# Part 1. 전투 유닛 그림 자리 — `BattleUnitArt`

## 전투 화면의 구조

전투 유닛은 코드로 만들지 않고 **씬에 놓인 틀을 복제**해서 쓴다. 고치기 전에 씬 파일을 읽어 구조를 확인했다.

| 항목 | 값 |
| --- | --- |
| 유닛 한 칸 | 월드 캔버스 190×285 (화면 높이의 약 17%) |
| 바디 | 그 안의 색 상자 125×157. 이름 글자가 상자 안에 있음 |
| 배치 | 아군은 화면 왼쪽(x -3 ~ -4), 적은 오른쪽(x 3 ~ 5) |
| 카메라 | 직교 · 세로 10단위 |

## 그림을 찾는 순서

| 대상 | 순서 |
| --- | --- |
| 아군 | `Resources/BattleUnits/{캐릭터ID}.png` (SD) → 스탠딩 전신 → 색 상자 |
| 몬스터 | `Resources/BattleUnits/{몬스터ID}.png` (SD) → 색 상자 |

SD 그림은 GPT에 요청해 둔 상태다. 그림이 오기 전에도 **아군은 스탠딩이 작게 보인다.** 몬스터는 색 상자가 그대로 남는다.

## 그림이 들어갈 때 바뀌는 것

| 항목 | 색 상자 | 그림 |
| --- | --- | --- |
| 영역 | 칸 가운데 125×157 | 체력바 바로 위부터 넓게 228×188 |
| 기준점 | 가운데 | **발 쪽** (그림 크기가 달라도 발이 바닥에 붙는다) |
| 색 | 역할 색 · 적군 색 | 원래 색 |
| 이름 | 상자 안 | 몬스터는 머리 위 작은 글자, 아군은 숨김 (아래 카드에 이름이 있다) |
| 보스 | 같은 크기 | `MON_BOSS_`로 시작하면 **1.5배** |

## 피격 표시

지금까지는 맞는 순간 상자를 **흰색**으로 번쩍였다. 그림은 원래 색이 흰색(색을 곱하지 않은 상태)이라 흰색으로 바꿔도 **아무 변화가 없다.**

→ 그림 유닛은 잠깐 **붉게** 물들인다. 색 상자는 예전처럼 흰색이다.

# Part 3. 배경 연결 바로잡기

## 발견

전투 배경을 지역에 맞추려고 받은 그림을 하나씩 다시 열어 봤다. 그러다 **장면과 그림이 맞지 않는 곳**이 나왔다.

| 배경 키 | 대사에서 쓰는 장소 | 실제 그림 |
| --- | --- | --- |
| `NOIR` | 노아르 마법도시 · 의회 광장 · 지하 서고 · 연구실 | 어둡게 부서진 **침식 공간** |
| `SEA_RIFT` | 서쪽 해안 1편 + **옥좌 · 심연 · 엔딩 7편** | 폭풍 치는 **바다** |

## 원인 두 가지

1. **내가 잘못 적었다.** 75일차에 GPT로 넘긴 문서에서 `NOIR`를 "어두운 침식 공간"이라고 설명했다. 게임에서 노아르는 푸른 마법등이 켜진 도시다
2. **배경 키를 분위기로 빌려 썼다.** 71~72일차에 최종장 대사를 쓸 때, 어두운 보랏빛 분위기가 비슷하다는 이유로 옥좌 장면에 `SEA_RIFT`를 썼다

코드로 그린 그라데이션일 때는 색만 비슷하면 문제가 없었다. **일러스트가 되자 "어디인가"가 그림에 그려져 버렸다.**

## 고친 것

**그림에 제 이름을 붙였다.** `NOIR.png` → `ABYSS.png` (그림은 그대로, 이름만)

**심연 · 옥좌 장면 9편을 `ABYSS`로**

| 대사 | 장소 | 전에 나오던 그림 |
| --- | --- | --- |
| CH5_05 | 지하 고대 도시 · 봉인실 | 햇빛 드는 사막 |
| CH5_06 | 지하 고대 도시 · 심연의 입구 | 바다 |
| CH6_03 · CH6_05 | 마왕성 최심부 · 무명의 옥좌 | 바다 |
| CH6_04 | 마왕성 최심부 · 관이 모이는 방 | 바다 |
| CH6_06 | 마왕성 · 지상으로 오르는 계단 | 마을 광장 |
| ENDING_02 · 03 · 04 | 엔딩 (옥좌) | 바다 |

**노아르 장면 5편을 장소별로**

| 대사 | 장소 | 배경 키 | 지금 나오는 그림 |
| --- | --- | --- | --- |
| CH3_01 · CH3_03 · 노아르 도착 | 마법도시 거리 · 광장 | `NOIR` | 밤의 관측실 (임시) |
| CH3_02 | 금지된 지하 서고 | `NOIR_ARCHIVE` | 밤의 관측실 (임시) |
| CH3_05 | 릴리아의 옛 연구실 | `ALCHEMY_LAB` | 노아르 실험실 |

도시와 서고는 맞는 그림이 아직 없다. 밤의 관측실 그림에 창밖 마법도시와 책장이 있어 가장 가깝다. 두 장을 GPT에 요청했다.

## 대체 배경을 여러 단계로

노아르 전투는 지하 서고 그림을 쓰고 싶은데, 서고 그림도 아직 없다. 그래서 대체 배경이 **사슬처럼 이어지게** 했다.

`BATTLE_NOIR` → `NOIR_ARCHIVE` → `OBSERVATORY_NIGHT`

서고 그림이 들어오면 대사와 전투 양쪽이 함께 바뀐다. 순환을 막으려고 따라가는 횟수는 4번까지다.

# Part 4. 모험 지도 지역 아이콘 — `AdventureRegionArt`

## 받은 그림

3×3으로 아이콘 9개가 그려진 시트 한 장(1254×1254, 투명 배경)이었다.

- 투명한 줄과 칸을 찾아 **9칸의 경계를 자동으로** 잡았다
- 가장 큰 칸에 맞춘 **386×386 정사각**에 하나씩 옮겨 담았다. 크기가 같아야 지도에서 고르게 보인다

## 연결

시트에 지역 이름이 없어 모양을 보고 정했다. **게임의 9개 지역과 딱 맞지는 않았다.**

| 그림 | 지역 |
| --- | --- |
| 파란 깃발 탑과 나무 | 숲 |
| 황금 돔과 야자수 | 사막 |
| 교차한 검과 붉은 깃발의 요새 | 마을 (추측) |
| 초록 불빛이 도는 큰 나무 | 실바란 |
| 톱니와 수정이 달린 탑 | 노아르 |
| 설산과 눈꽃 | 카르니안 (추측) |
| 고목과 가마솥 | 늪지대 |
| 붉은 소용돌이의 검은 문 | 마왕성 |
| 날개 달린 구름 위 신전 | 쓰지 않음 |

바다 아이콘은 없어서 바다는 색 원으로 남는다.

## 지도에서 달라진 것

| 항목 | 전 | 후 |
| --- | --- | --- |
| 지역 표시 | 색 원 + 첫 글자 | 아이콘 + 납작한 받침 |
| 상태 색 (침식도) | 원 색 | **받침 색에 그대로** |
| 잠긴 지역 | 회색 원 | 아이콘을 어둡게 |
| 누를 수 있는 범위 | 원 62×62 | 아이콘까지 |
| 새 던전 "!" | 원 위 | 아이콘 머리 위 |

상태 색은 침식도를 알려 주는 정보라서 없애지 않고 받침으로 옮겼다.

## 알아둘 점

- **대사의 배경은 분위기가 아니라 장소로 고를 것.** 다른 장소의 키를 빌려 쓰면 엉뚱한 그림이 나온다. 새 장소면 키를 새로 만들고 `DialogueArtFactory`에 대체 배경을 적는다
- **그림 요청문을 쓰기 전에 코드에서 그 이름이 무슨 뜻인지 확인할 것.** `NOIR` 설명을 잘못 적어 그림 한 장이 다른 장소로 그려졌다
- SD 그림은 화면 높이의 11% 정도로 작게 보인다. 한 화면에 아군 4명과 적 5명이 서는 배치라서다
- 채팅에 붙여 넣은 그림은 WebP 사본이다. 원본 PNG를 쓴다
- 지역 아이콘의 마을 · 카르니안 연결은 추측이다. 바꾸려면 파일 이름만 바꾸면 된다
