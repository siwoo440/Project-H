# 프로젝트 H : 62일차 개발 로그

## 오늘 목표

62일차는 사용자 목업(1 · 5~9번)을 바탕으로 두 가지를 만들었고, 추가 요청으로 시간 전환 연출을 넣었다.

1. **마을 씬** — 여관 · 광장 · 시장 · 온천 · 길드 5구역, 시간대마다 무작위로 나타나는 캐릭터, 구역 이벤트, 시간 · 일차 소비
2. **대화 UI 개편** — 2인 좌우 스탠딩, 이름/소속 이름표, 우상단 아이콘 메뉴(자동 · 건너뛰기 · 숨김 · 로그 · 설정), 밝은 회색 창
3. **시간 전환 연출** (추가 요청) — 시간이 지나면 왼쪽 시간대 그림이 바뀌고, 오른쪽 글자가 "아침 → 점심"처럼 넘어감

기획서 참고 범위: 9장 마을(9.2 시장 : 호감도 아이템 · 미니게임 · 호감도 이벤트, 나머지 구역은 제목만) · 대화 표(자동 · 건너뛰기 확인 창 · UI 비활성화 · 대화 로그 · 설정) · 5.7 결속 자원

# Part 1. 마을 씬

## 1. 들어가는 법과 화면

로비 하단 버튼이 **파티 · 모험 · 캐릭터 · 마을 · 대장간 · 상점 · 가방**이 되었다. [마을]은 대장간 바로 왼쪽 칸이다.

```text
[◀ 뒤로]  마을            DAY 3 · 저녁       활력 70/100  결속 자원 2/5  ● 1,250 G
   ┌ 여관 ─────────┐                     ┌ 길드 ─────────┐
   │ ● 세레나       │    ┌ 광장 ───────┐  │ ● 엘렌         │
   └───────────────┘    │ 아무도 없음   │  └───────────────┘
   ┌ 시장 ─────────┐    └─────────────┘  ┌ 온천 ─────────┐
   │ ● 릴리아       │                     │ ● 이브         │
   └───────────────┘                     └───────────────┘
[안내 : 구역을 눌러 들어가 보세요 …]
```

| 화면 | 내용 |
| --- | --- |
| 지도 | 구역 카드 5개. 카드마다 지금 그곳에 있는 캐릭터 이름, 밤의 시장은 "영업 종료" |
| 구역 | 구역 배경 · 캐릭터 스탠딩(최대 2명, 누르면 선택) · 오른쪽 행동 패널 · [◀ 뒤로]로 지도 → 로비 |
| 상단 | 일차 · 시간대, 활력 · 결속 자원 · 골드 |

씬은 다른 메뉴 씬처럼 빈 `Village.unity`에 `VillageSceneRuntimePatch`가 카메라와 화면을 넣는다.

## 2. 무작위 캐릭터 배치 (`VillagePresenceService`)

- 캐릭터마다 **선호 구역 가중치**가 있다. 예: 세레나 광장 · 여관, 엘렌 길드, 릴리아 시장 · 여관, 이브 온천 · 광장
- **일차 + 시간대를 해시한 난수**로 정하므로 같은 시간대에는 저장 · 재시작해도 배치가 같다(세이브 스컴 방지)
- 가끔은 "외출 중"이라 마을에 없고, 한 캐릭터는 한 곳에만 있다. 시장은 밤에 닫혀 아무도 없다
- 64일차 합류 8인의 가중치도 미리 넣어 두어, 합류하면 바로 마을에 나타난다

## 3. 구역 행동과 시간 · 일차 소비

| 구역 | 행동 | 소비 |
| --- | --- | --- |
| 공통 | 대화하기 (58일차 일상 대화) | 없음 (시간대당 1회 그대로) |
| 공통 | 선물하기 (57일차 선물 패널 재사용) | 없음 (하루 3회 그대로) |
| 광장 · 시장 · 온천 · 길드 | **함께 시간 보내기** — 구역 전용 대사, 호감도 +3 + 선택지 | 시간대 1칸 · 캐릭터당 하루 1회 |
| 시장 | 상점 · 대장간 바로가기 | 없음 |
| 온천 | 온천에 몸 담그기 — 활력 +30 | 시간대 1칸 (밤이면 다음 날) |
| 여관 | 방 잡고 잠자기 (저녁 · 밤만) | 다음 날 아침 · 활력 전체 회복 |
| 여관 | **특별한 밤** (진입 구조) | 결속 자원 1 · 다음 날 아침 |
| 길드 | 의뢰 게시판(67일차 전까지 던전 정보) · 모험 떠나기 | 없음 |

- 행동 결과는 즉시 저장한다. 시간이 흘러 캐릭터가 떠나면 선택이 풀리고, 시장이 닫히면 지도로 돌아간다
- 기존 세이브는 캐릭터별 "오늘 마을 이벤트 · 특별한 밤" 기록이 없음으로 시작한다

## 4. 여관 특별한 밤 — 진입 구조만

62일차 계획에서 정한 대로 **들어가는 구조만** 만들었다.

1. 조건 : **밤** · 그 캐릭터가 여관에 있음 · **결속 3단계 이상** · **결속 자원 1** · 하루 1회
2. 암전(0.6초) → 대사 `INN_{캐릭터}` → 끝까지 보면 결속 자원 -1 · 호감도 +5 · **다음 날 아침** → 밝아짐
3. 대사는 방에서 나누는 짧은 대화와 "등불이 꺼졌다" 암시까지만 쓰고, 선정적인 내용은 넣지 않았다

## 5. 대사 20편

| 종류 | 파일 | 수 |
| --- | --- | --- |
| 구역 이벤트 | `VILLAGE_{PLAZA · MARKET · ONSEN · GUILD}_{SERENA · ELLEN · LILIA · EVE}` | 16 |
| 특별한 밤 | `INN_{SERENA · ELLEN · LILIA · EVE}` | 4 |

모든 편에 선호 선택지(호감도 +2)가 있다. 예: 세레나와 분수대에 동전 던지기, 엘렌과 숫돌 흥정, 릴리아의 비둘기 궤도 관찰, 이브와 온천 물의 정령. 온천 이벤트는 족욕 · 울타리 너머 대화처럼 일상 장면으로 구성했다.

# Part 2. 대화 UI 개편 (목업 1번)

```text
「분수대의 동전」 마을 · 광장                    (▶)(▶▶)(◎)(≡)(⚙)
                                                  자동 건너뛰기 숨김 로그 설정
   ┌───────┐                        ┌───────┐
   │ 세레나 │  ← 말하는 쪽 밝게       │ 릴리아 │  ← 듣는 쪽 어둡고 조금 작게
   │       │                        │       │
┌ 세레나 · 레티시아 왕국 ┐
│ 아, 오셨군요. 아이들이 분수에 동전을 던지면 소원이 이뤄진다고 해서요.   ▼ │  ← 밝은 회색 창
```

| 항목 | 내용 |
| --- | --- |

# Part 3. 시간 전환 연출 (추가 요청)

```text
┌───────────────────────── (뒤 화면 살짝 어둡게) ─────────────────────────┐
│   ┌────────────┐   DAY 3                                                  │
│   │ 해 뜬 언덕  │   아침   ↑ 위로 빠지며 흐려짐                           │
│   │ → 한낮 하늘 │   점심   ↑ 아래에서 올라옴                              │
│   └────────────┘   해가 머리 위에 높이 떴다.                              │
└────────────────────────────────────────────────────────────────────────────┘
```

| 요소 | 내용 |
| --- | --- |
| 알림 | 모든 시간 진행이 거치는 `GameTimeService.AdvanceTime`이 **변화(이전 · 이후 일차와 시간대)를 알린다**. 연출은 이 알림만 구독하므로 로비 시간 진행 · 마을 행동 · 잠자기 · 특별한 밤 모두 자동으로 나오고, 이후 추가되는 기능도 따로 연결할 필요가 없다 |
| 왼쪽 그림 | 아침(왼쪽 낮은 해) · 점심(가운데 높은 해) · 저녁(오른쪽 노을) · 밤(초승달 · 별)을 서서히 교차하고, 테두리 색도 시간대 색으로 바뀐다 (`TimeOfDayArt`, `Resources/TimeOfDay/`에 정식 그림을 넣으면 교체) |
| 오른쪽 글자 | 이전 시간대는 위로 빠지고 다음 시간대가 아래에서 올라온다. 날이 바뀌면 "DAY 3 → DAY 4"도 함께 넘어가고 "새로운 하루 · 활력이 모두 회복되었다"가 붙는다 |
| 합치기 | 잠자기처럼 저녁 → 밤 → 아침으로 연속 진행하면 **"저녁 → 아침" 한 번**으로 보여 준다 |
| 시간 | 약 2.8초. 화면을 누르면 결과로 바로 넘어가고, 한 번 더 누르면 닫힌다. 씬이 바뀌어도 끝까지 재생된다 |

- 낮 시간대 표기는 사용자 예시에 맞춰 **"낮" → "점심"**으로 통일했다(마을 · 결과 안내 · 이벤트 조건 문구)

## 문제 해결 : 마을 버튼을 누르면 "No cameras rendering"

- 원인 : `VillageSceneRuntimePatch.cs`를 만드는 순간 Unity가 새로고침 중이어서, `.meta`가 본문보다 1초 먼저 생긴 채 **스크립트로 등록되지 않았다**. Unity 컴파일 결과(`ProjectH.Runtime.dll`)와 컴파일 대상 목록에서 이 파일만 빠져, 마을 씬에 카메라 · 화면이 생기지 않았다
- 해결 : 이 파일의 `.meta`를 새 GUID의 정식 스크립트 메타로 다시 만들어 Unity가 새 스크립트로 가져오게 했다. 카메라 확인도 켜진 카메라만 세도록(`Camera.allCamerasCount`) 보강했다
- 재발 방지 : 이후 새 스크립트는 `.meta`를 먼저 정식으로 만들고, 커밋 전에 Unity 컴파일 결과에 새 클래스가 들어갔는지 확인한다

## 보강 : 무작위 뽑기 품질

마을 배치와 61일차 상점 오늘의 상품의 난수 시드를 "ID | 일차 | 시간대(리롤)" 문자열 전체 해시로 바꿨다. .NET 난수는 시드가 가까우면 첫 값도 비슷하게 나와서, 이웃한 날끼리 결과가 닮는 문제를 막았다.

## 알아둘 점

- 캐릭터 스탠딩 · 구역 배경 · 시간대 그림은 모두 임시다. `Resources/Dialogues/Standing/{캐릭터ID}` · `Resources/Dialogues/Backgrounds/VILLAGE_PLAZA` 등 · `Resources/TimeOfDay/MORNING` 등에 넣으면 자동으로 교체된다
- 구역 이벤트와 특별한 밤 대사는 초기 4인만 있다. 64일차 합류 캐릭터는 마을에 나타나지만 "함께 시간 보내기"는 대사 파일이 생길 때(64 · 70일차) 열린다
- 로비 상단의 "DAY 1 · Morning" 영어 표기는 따로 쓰는 로비 코드라 그대로다(63일차 메인 메뉴 정리 때 함께 바꿀 예정)
