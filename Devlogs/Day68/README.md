# 프로젝트 H : 68일차 개발 로그

## 오늘 목표

68일차는 **이야기**를 넣었다. 지금까지는 게임을 켜면 설명 없이 로비로 떨어졌지만, 이제 소환 장면부터 시작해 동료를 하나씩 만나며 진행한다.

| 기능 | 한 줄 설명 |
| --- | --- |
| ✍️ 주인공 이름 | 새 게임에서 이름을 정하고, 모든 대사에서 그 이름으로 불린다 |
| 📖 챕터 시스템 | "이야기 보기 → 던전 클리어 → 다음 이야기" 순서로 진행되고, 로비에 다음 할 일이 보인다 |
| 📜 프롤로그 · 챕터 1 · 2 | 대사 10편, 선택지 포함. 세레나 → **루시아(길드 용병)** → 엘렌 → 릴리아 · 이브 순으로 합류 |
| ⚔️ 초반 2인 파티 | (추가 요청) 길드에서 딜러 용병을 고용해 **세레나 + 루시아**로 첫 던전에 간다 |

사용자와 정한 방식(추천안)

1. 이름 기본값 "용사", 1~8자
2. 이름은 처음 한 번만 정함(변경은 72일차 설정에서 검토)
3. 프롤로그는 기존 SKIP 버튼으로 건너뛸 수 있음
4. 기존 세이브는 동료·진행을 그대로 두고 스토리를 건너뜀
5. 첫 전투 안내는 대사 안에서 간단히(자세한 튜토리얼은 72일차)

# Part 1. 주인공 이름

```text
┌──────────────────────────────────────┐
│        당신의 이름을 알려 주세요        │
│   8자까지 · 비우면 '용사'로 시작합니다   │
│   ┌──────────────────────────────┐   │
│   │ 아리안                        │   │
│   └──────────────────────────────┘   │
│        [ 이 이름으로 시작 ]           │
└──────────────────────────────────────┘
```

| 항목 | 내용 |
| --- | --- |
| 시점 | 새 게임 후 **로비에 처음 들어갈 때** 1회 (타이틀 버튼을 건드리지 않아 기존 흐름이 그대로 유지된다) |
| 규칙 | 앞뒤 공백 제거 · 최대 8자 · 비우면 "용사" |
| 반영 | 대사 본문 · 선택지 · 대화 로그 · 이름표까지 모두 입력한 이름 |
| 방법 | 대사 파일에 `{HERO}`를 적으면 표시할 때 실제 이름으로 바뀐다 |
| 기존 세이브 | 이름 칸이 비어 있으므로 다음 로비 진입 때 한 번 묻는다 |

# Part 2. 챕터 시스템

| 요소 | 내용 |
| --- | --- |
| 챕터 | 제목 + **단계 목록** |
| 단계 종류 | **이야기 보기**(대사 ID) · **던전 클리어**(던전 ID) |
| 단계 옵션 | "이 단계를 마치면 합류하는 동료" 지정 가능 |
| 저장 | 현재 챕터 ID + 단계 번호 |
| 표시 | 로비 상단에 `챕터 1 · 숲의 침식` / `다음: 무너진 성역의 숲 클리어` |
| 자동 재생 | 로비에 들어올 때 다음 이야기가 있으면 바로 재생하고, 끝나면 이어지는 이야기까지 연속 재생 |
| 자동 통과 | 이미 깬 던전 단계는 화면을 열 때 건너뛴다 |
| 기존 세이브 | 동료가 여럿이거나 이미 진행한 흔적이 있으면 **스토리 완료 상태로 시작**(대사 재생 없음) |

## 알아둘 점

- 챕터를 늘릴 때는 `ChapterCatalog`에 단계를 추가하고 대사 파일만 만들면 된다. 합류 동료는 단계에 ID만 적으면 처리된다
- 대사에서 주인공을 부를 때는 `{HERO}`를 쓴다. 화자 이름표는 자동으로 입력한 이름이 된다
- 새 게임이 1인으로 시작하므로, 초반 던전 난이도를 바꿀 때는 **2인 기준**으로 확인해야 한다
- 69일차 챕터 3~5를 넣으면 `ChapterService`가 자동으로 이어서 진행한다(완료 상태였던 세이브는 새 챕터부터 다시 시작하지 않으므로, 이어 붙일 때 진행 위치 처리를 확인할 것)
