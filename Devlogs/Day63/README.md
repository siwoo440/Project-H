# 프로젝트 H : 63일차 개발 로그

## 오늘 목표

63일차는 사용자 목업 10 · 11번을 바탕으로 두 가지를 만들었고, 추가 요청으로 일기장 CG 화면을 다듬었다.

1. **모험 지도** — 던전 선택 목록을 세계 지도 한 장으로 교체 (숲 · 늪지대 · 마왕성 · 마을 · 사막 · 바다)
2. **일기장** — 타이틀 · 로비의 [일기장] 버튼, 시나리오 · CG · 컷신 다시 보기, 몬스터 정보 · 세계관 좌우 패널
3. **CG · 컷신 화면** (추가 요청) — 오른쪽 2×3 그림 칸, 사진 · 동영상 아이콘, CG는 가운데 "재생하겠습니까?", 정지 컷신은 전체 화면 휠 확대, 개발용 테스트 칸

기획서 참고 범위: 2장 세계관(2.1~2.7 대륙 · 신화 · 지역 · 세력 · 침식 · 핵심 용어) · 11장 일기장("시나리오 재감상 및 CG, 컷신 재감상, 몬스터 정보, 세계관 설명") · 12장 모험 · 대화 표의 건너뛰기 문구("일기장을 통해 다시 감상이 가능")

- 지역 원의 색은 **침식도 등급**(안정 초록 → 붕괴 자주), 마을은 금색, 잠긴 지역은 회색이다

- 전투에서 돌아오면 방금 간 던전의 지역이 선택된 채로 열린다
- 전투 복귀 흐름을 그대로 쓰려고 씬은 `DungeonSelect`를 유지하고 화면만 교체했다. 활력 소비(61일차) · 노드 탐험(55일차) · 순차 해금 · 별점(47일차)은 그대로 동작한다
- 옛 목록 화면의 카드를 이름으로 찾아 색을 칠하던 `DungeonProgressUiRuntimePatch`는 지도 화면에 기능을 통합하고 **삭제**했다

# Part 3. CG · 컷신 화면 (추가 요청)

```text
┌ 왼쪽 (목록) ──────────────┐┌ 오른쪽 (2×3 그림 칸) ───────────┐
│ CG · 테스트 · 노을 CG       ││ ┌────────[▶]┐ ┌────────[▣]┐     │
│ 컷신(정적) · 테스트 · 밤의 성역││ │ 노을 CG   │ │ 밤의 성역  │     │
│ CG · 세레나 · ???          ││ ├───────────┤ ├───────────┤     │
│ …                         ││ │    ?      │ │    ?      │     │
│                           ││ ├───────────┤ ├───────────┤     │
│                           ││ │    …      │ │    …      │     │
│ ◀ 1/2 ▶                   ││ └───────────┘ └───────────┘     │
└───────────────────────────┘│          ◀ 1 / 3 ▶              │
                              └────────────────────────────────┘
       [▶] = 동영상 아이콘 (재생)   [▣] = 사진 아이콘 (정지 컷신)
```

| 칸 종류 | 아이콘 | 누르면 |
| --- | --- | --- |
| **CG** | 동영상 | 그림 없이 **화면 가운데 "CG를 재생하겠습니까?"** — [네] 그 CG가 나오는 장면 재생 · [아니요] 바로 닫힘 (닫기 버튼 · 안내 글자 없음) |
| **궁극기 컷신** | 동영상 | 가운데 "컷신을 재생하겠습니까?" — [네] 궁극기 컷인 재생(결속 5단계면 금빛) |
| **컷신(정적)** | 사진 | **전체 화면 크게 보기** — 휠 확대/축소(1~4배, 커서 기준) · 드래그 이동 · 왼쪽 위 안내 글자 · [✕ 닫기] · ESC/오른쪽 클릭 |

- 아이콘은 **눌렀을 때 일어나는 일**로 정했다(사진 = 크게 보는 정지 그림, 동영상 = 재생되는 것). `DiaryBadgeArt`가 그리고, `Resources/Diary/Icons/PHOTO` · `VIDEO`로 교체할 수 있다
- 왼쪽 줄을 누르면 그 칸이 있는 쪽으로 넘어가 금테로 표시된다
- CG 12장(캐릭터당 개인 1화 · 결속 5단계 · 특별한 밤)은 연결된 이야기를 보면 열린다. 정식 CG 전까지는 이야기 배경 + 캐릭터 실루엣이다

## 대사 중 CG 표시

대사 줄에 `"cg": "CG_ID"`를 넣으면 그 줄부터 `Resources/Diary/CG/CG_ID`가 화면 가득 나오고 스탠딩이 숨겨진다. `"cg": "-"`면 원래 배경으로 돌아온다. "CG 재생"을 누르면 이 방식으로 CG가 실제로 나오는 장면을 본다.

## PNG를 그대로 넣어도 되는 그림 불러오기

이 프로젝트는 PNG를 기본 Texture로 가져온다. `RuntimeSpriteLoader`가 Sprite가 아니어도 그림으로 바꿔 주므로, CG · 정지 컷신 · 대화 배경 · 스탠딩 · 컷인 · 세계 지도 · 시간대 그림 모두 **PNG를 넣기만 하면** 바로 표시된다.
