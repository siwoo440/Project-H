## 오늘 목표

60일차는 재압축 일정의 **룬 데이터 · 장착 + 룬 강화 · 합성**을 진행했고, 사용자 요청으로 두 가지를 함께 넣었다.

3. **장비 5칸** — 룬처럼 일러스트 둘레에 무기 · 투구 · 방어구 · 장갑 · 신발

# Part 1. 룬 시스템

## 1. 룬 15종

룬은 캐릭터에게 끼우는 "능력 보석"이다. 장비가 기본 능력치를 올린다면, 룬은 **싸우는 방식을 바꾼다**(기획서 8.3).

| 분류 | 룬 | ★1 / ★2 / ★3 | 반영 방식 |
| --- | --- | --- | --- |
| 공격 | 힘 | 공격력 +10 / 15 / 20% | 스탯 |
| 공격 | 치명타 | 치명타율 +10 / 20 / 30%p | 스탯 |
| 공격 | 광기 | 체력 50% 이하일 때 공격력 +15 / 25 / 35% | 0.25초마다 체력 확인 |
| 공격 | **전투** | **흐트러짐 누적** +10 / 20 / 30% | Day53 흐트러짐 |
| 공격 | **흡혈** | **준 피해의** 3 / 6 / 9% 회복 | 피해 적용 시 |
| 공격 | **신속** | 공격 속도 **+0.1 / 0.2 / 0.3** | 스탯 |
| 방어 | 수비 | 방어력 +10 / 20 / 30% | 스탯 |
| 방어 | 체력 | 최대 체력 +5 / 10 / 15% | 스탯 |
| 방어 | 보호막 | 5초마다 최대 체력 3 / 6 / 9% 보호막 | Day20 보호막 재사용 |
| 방어 | 가시 | 피격 시 공격력의 5 / 7 / 9% 반사 | 피해 적용 시 |
| 방어 | 민첩 | 적 공격 회피 5 / 10 / 15% | 피해 적용 전 |
| 회복 | 재생 | 매초 최대 체력 1 / 2 / 3% 회복 | 1초마다 |
| 특수 ◆ | **궁극** | **궁극기 게이지 충전** +15 / 20 / 25% | Day59 게이지 배율 |
| 특수 ◆ | **스킬** | **스킬 블록 생성 주기** -10 / 15 / 20% | Day17 블록 생성기 |
| 특수 ◆ | 부활 | 쓰러지면 1회 체력 10 / 20 / 30%로 부활 | 사망 처리 |

◆ = 기획서의 "1개만 소지 가능". 같은 특수 룬은 **캐릭터당 1개만** 장착할 수 있다.

### 구조에 맞춰 바꾼 5개 (굵게 표시)

| 룬 | 기획서 원문 | 바꾼 이유 |
| --- | --- | --- |
| 신속 | 공격 속도 +1 / 2 / 3 | 기본 공격 속도가 약 1.0이라 +1이면 공격이 두 배 |
| 전투 | 적 보호막 피해 증가 | 적에게 보호막이 거의 없음 → 흐트러짐 게이지로 연결 |
| 궁극 | 궁극기 필요 횟수 -1 | 궁극기가 횟수가 아니라 게이지 방식 |
| 스킬 | 스킬 생성 속도 +1 | 스킬이 블록 생성 주기(1.5초) 방식 |
| 흡혈 | 적중 시 체력 3% 회복 | 최대 체력 기준이면 공격 속도가 빠를 때 과함 |

## 2. 강화 · 합성 · 분해 · 잠금

**최종 효과 = 등급 수치 × (1 + 0.05 × (레벨 − 1))**. Lv.10이면 +45%이고, ★3 힘 룬은 20% → 29%가 된다.

| 기능 | 규칙 |
| --- | --- |
| 강화 | 룬 조각 + 골드로 Lv.1 → Lv.10. Lv.2~3 조각 1~2 · 50~100G, Lv.6~9 조각 5~8, Lv.10 조각 10 · 1000G. 등급이 오르면 비용 ×2 / ×4. **실패 없음** |
| 합성 | 같은 종류 · 같은 등급 2개 + 골드(100G / 200G) → 한 등급 위 Lv.1. 재료에 들인 **강화 조각의 50%를 반환** |
| 분해 | ★1 → 조각 2 · ★2 → 5 · ★3 → 12, 강화 레벨만큼 추가 |
| 잠금 | 잠긴 룬과 장착 중인 룬은 합성 · 분해 재료로 쓸 수 없음 |

- 강화 실패는 스트레스가 커서 넣지 않았다
- 합성 짝은 **같은 종류 · 등급 중 레벨이 가장 낮은 룬**을 자동으로 고른다. 강화한 룬을 실수로 재료로 쓰는 일을 줄이기 위해서다
- 모든 수치는 `RuneCatalog` 한 파일에서 조정한다

## 3. 룬 슬롯 5칸

기획서 8.12 "캐릭터당 3~5개"와 목업의 5칸 배치에 맞췄다.

| 칸 | 위치 | 해금 조건 |
| --- | --- | --- |
| 1 | 좌상 | 기본 |
| 2 | 우상 | 레벨 10 |
| 3 | 좌하 | 결속 3단계 (Day59) |
| 4 | 우하 | 고급 이상 장비 착용 (장비 5칸 중 하나) |
| 5 | 하단 | 결속 5단계 (임시) |

5번의 기획서 조건은 "전용 장비 초월"이다. 전용 장비가 생기는 Day61에 바꿀 수 있게 조건을 `RuneService.IsSlotUnlocked` 한 곳에 모았다. 칸이 차 있으면 **교체**되고, 다른 캐릭터가 쓰던 룬을 장착하면 그 캐릭터에서 빠져 옮겨온다.

## 5. 전투 반영

### 스탯형 — 장비 보너스와 함께

`BattleEquipmentStatCalculator`가 장비 합계를 만들 때 **장착 룬 합계(`RuneLoadout`)를 함께 붙이고**, `BattleStatsFactory`가 스탯을 만들 때 적용한다. 장비 계산을 쓰는 곳(전투 파티 생성 · 캐릭터 창 · 장비 미리보기)이 모두 자동으로 룬을 반영한다. 룬이 없으면 모든 수치가 **기존과 완전히 같다**.

### 발동형 — `BattleRuneRuntimeState` · `BattleRuneEffects`

| 시점 | 룬 |
| --- | --- |
| 전투 드라이버 Tick | 광기(0.25초) · 재생(1초) · 보호막(5초) |
| `BattleActor.ApplyDamage` 시작 | 민첩 회피 (공격자가 없는 지속 피해는 제외) |
| `BattleActor.ApplyDamage` 직후 | 흡혈(공격자) · 가시(피해자, 반사 피해가 다시 반사되지 않게 보호) · 부활(피해자) |
| 흐트러짐 누적 | 전투 (공격자 룬 기준) |
| 궁극기 게이지 | 궁극 (Day59 결속 배율에 합산) |
| 블록 생성 | 스킬 (파티 중 가장 높은 값 1개 적용) |

- 부활은 세레나 궁극기와 같은 `BattleDeathHandler.TryRevive` 경로를 쓰고, 전투당 1회다
- 룬 등록은 Day59 결속과 같은 **등록형**이다. 스탯 생성 시 등록하고, 전투 시작 초기화에서는 지우지 않으며, 룬이 없는 캐릭터로 다시 만들면 잔여 등록이 지워진다(Day55 테스트 누수 규칙)

# Part 2. 캐릭터 창 재구성 (사용자 목업)

```text
[◀ 캐릭터]                         [?] (G 10,000) [⚙]
   ◀ 세레나 Lv.12 ▶        [스텟][장비][룬][스킬][프로필]
[칸1]┌─────────┐[칸2]      ┌───────────────────────────┐
     │ 일러스트 │           │ 선택한 탭 내용              │
[칸3]│         │[칸4]      │                           │
     └─────────┘           │                           │
         [칸5]             │ 공용 상태 문구              │
```

| 영역 | 내용 |
| --- | --- |
| 상단 바 | ◀ 캐릭터(로비 복귀) · ? 도움말 · 골드 · ⚙ 설정(Day71 안내) |
| 좌측 | ◀ ▶ 캐릭터 전환 · 이름 · 레벨 · 흰 일러스트 칸. 탭에 따라 둘레 5칸이 **장비 칸 또는 룬 칸**으로 바뀜 |
| 스텟 탭 | 최종 능력치 · 성장/관계 정보(레벨 · 호감도 · 결속 · 결속 자원 · 오늘 선물 · 일상 대화 · 장착 룬 수) · [호감도 보상] [선물하기] [대화하기] [결속] |
| 장비 탭 | Day36 장비 화면을 탭 안으로 이동 (목록 · 상세 · 변경 전후 비교) |
| 룬 탭 | 보유 룬 목록(2열) · 분류 필터 · 상세 · [장착 · 해제 · 강화 · 합성 · 분해 · 잠금] · 역할별 추천 룬(기획서 11.12) |
| 스킬 탭 | 스킬 1~3 · 궁극기와 기합 대사 · 패시브 · 결속 스킬 |
| 프로필 탭 | 두 번째 목업 그대로: 이름 · CV · 키/몸무게 · 3사이즈 · 스토리 |

- Day56~59의 하단 바 버튼들은 **스텟 탭 안**으로 옮겼다. 호감도 ±10 디버그 버튼도 스텟 탭에 있고 출시 빌드에서 숨긴다
- 일러스트는 정식 스탠딩 전까지 Day58 임시 실루엣(캐릭터 색)을 쓴다
- 룬 아이콘은 원형 발광 + 룬 글자(힘 · 치 · 광 …)이며 분류별 색으로 구분한다(공격 빨강 · 방어 파랑 · 회복 초록 · 특수 분홍)
- 프로필은 기획서 캐릭터 시트에서 가져왔고(`CharacterProfileCatalog`), 공란 · 확정 대기 항목(성우 전원, 이브 이후 대부분의 키 · 몸무게, 엘렌 나이 등)은 목업처럼 **`###`**으로 표시한다
- 탭 내용은 탭별 클래스로 나눴다: `CharacterRuneTab` · `CharacterSkillTab` · `CharacterProfileTab`

# Part 3. 장비 5칸 (사용자 추가 요청)

기존 화면에 "준비 중"으로만 있던 투구 · 장갑 · 신발을 실제 슬롯으로 만들었다.

```text
 [검 무기]  ┌─────────┐  [투 투구]
   철제 검  │ 일러스트 │   수호자 투구
 [갑 방어구]│         │  [장 장갑]
            └─────────┘
              [신 신발]
```

- `EquipmentSlot`에 투구(2) · 장갑(3) · 신발(4)을 추가하고, 5칸 순서 · 이름 · 아이콘 글자를 `EquipmentSlotInfo`에 모았다
- `CharacterEquipmentSaveData`에 세 칸을 추가했다. **기존 세이브는 새 칸이 빈 칸**으로 시작한다
- 장비 계산이 무기 · 방어구만 더하던 것을 **5칸 전체 합산**으로 바꿨다. 장착 · 해제 · 미리보기 서비스는 원래 슬롯을 일반화해 두어서 고칠 필요가 없었다
- 룬 탭과 **같은 자리**(`CharacterSlotLayout` 공유)에 칸을 두고, 칸 색은 장착 장비 등급, 칸 아래에는 장비 이름을 표시한다
- 칸을 누르면 오른쪽 목록이 **그 부위 장비만** 보이고 장착 중인 장비가 선택된다. [전체 보기]로 필터를 푼다

### 새 장비 6종 (임시 수치)

| 장비 | 등급 | 능력치 | 구하는 법 |
| --- | --- | --- | --- |
| 훈련용 투구 | 일반 | 체력 +60 · 방어 +5 | 테스트 장비 지급 |
| 수호자 투구 | 고급 | 체력 +110 · 방어 +10 · 저항 +5 | 상점 700G |
| 훈련용 장갑 | 일반 | 공격 +8 · 명중 +2% | 테스트 장비 지급 |
| 사냥꾼 장갑 | 고급 | 공격 +14 · 치명 +3% | 상점 800G |
| 훈련용 신발 | 일반 | 이동 +0.2 · 방어 +3 | 테스트 장비 지급 |
| 질풍 신발 | 고급 | 이동 +0.35 · 공속 +0.05 | 상점 750G |

ItemData와 EquipmentData 에셋 12개를 만들고 카탈로그의 `items` · `equipments` 목록에 모두 등록했다. 로비 상점 상품은 16개가 되었고, Day57의 2열 배치가 그대로 받아낸다.
