# Part 2. 씬에 놓인 화면 — `UiSkinScenePatch`

타이틀 · 로비 · 파티 · 전투 HUD는 4일차에 만든 임시 그림을 쓰고 있었다. 씬 파일을 고치지 않고, **씬이 열릴 때 임시 그림의 이름을 보고 새 스킨으로 바꾼다.**

## 대응표

| 임시 그림 | 새 스킨 |
| --- | --- |
| `frame_panel` | `panel_light` (밝은 창) |
| `frame_topbar` · `frame_bottombar` | `bar_top` · `bar_bottom` (남색 바) |
| `frame_portrait` · `frame_party_slot` 등 | `card` |
| `button_primary` | `button_primary` (금빛 주황) |
| `button_secondary` · `button_small` | `button_secondary` (청회색) |
| `button_nav` | `button_tab_on` (밝은 금색) |

## 글자가 묻히지 않게

임시 그림은 전부 밝은 색이었고 그 위의 글자는 어두웠다. 새 상단 · 하단 바는 **남색**이라 그대로 두면 글자가 보이지 않는다.

→ 어두운 스킨으로 바꾼 그림의 **바로 위에 놓인 어두운 글자만** 밝게 바꾼다. 자기 바탕을 가진 자식(버튼 · 칩) 아래의 글자는 건드리지 않는다.

## 내비 버튼에 남색을 쓰지 않은 이유

로비 내비 버튼과 파티 편성 버튼에는 요청해서 받은 남색 `button_nav`가 있다. 그런데 기존 코드가 이 버튼에 **어두운 글자색**과 **하늘색 선택 강조**를 입히고 있다. 남색 위에서는 둘 다 보이지 않는다.

→ 밝은 금색 탭 그림을 썼다. 남색 내비 버튼은 내비 아이콘과 함께 화면을 다시 짤 때 쓴다.

## 모서리 두께

9조각의 모서리는 그림의 픽셀 그대로 그려진다. 큰 창에는 알맞지만 작은 버튼에는 두껍다. 조각마다 기본 배율을 두었다.

| 조각 | 배율 |
| --- | --- |
| 큰 창 | 1.6 |
| 대화창 · 상단 · 하단 바 | 1.5 |
| 버튼 · 카드 · 칸 · 게이지 | 2 |

버튼 모양을 다른 버튼에서 복사하는 코드 5곳은 배율도 함께 복사하게 했다.

## 알아둘 점

- **창 · 버튼 그림은 `UiSkin.Apply`로 입힐 것.** 9조각 테두리와 모서리 배율을 함께 맞춘다
- **어두운 조각(`UiSkin.IsDark`) 위에는 밝은 글자를 올릴 것**
- 모서리가 두껍거나 얇으면 `UiSkin.GetCornerScale`의 숫자를 고친다. 값이 클수록 모서리가 작게 그려진다
- 씬에 놓인 임시 그림을 어떤 스킨으로 바꿀지는 `UiSkinScenePatch`의 대응표가 정한다
- 임시 그림과 새 스킨 중에 이름이 같은 것이 있다(`button_primary` 등). 이미 입힌 스킨인지는 `UiSkin.IsSkinSprite`로 구분한다
