# 프로젝트 H : 72일차 개발 로그

## 오늘 목표

71일차에 최종장이 끝났지만 **결말을 보여 주지 않았다**. 로비에 한 줄 뜨고 마는 상태였다. 72일차는 그 마지막을 제대로 보여 주고, 게임을 **끝내고 다시 시작할 수 있게** 만들었다.

| 갈래 | 내용 |
| --- | --- |
| 🎬 **엔딩 4종** | 최종장 두 선택의 조합마다 다른 결말 + 제목 카드 + 크레딧 |
| 📔 **엔딩 기록 · 뉴게임+** | 본 엔딩과 회차 수가 새로 시작해도 남는다 |
| ⚙️ **설정 · 접근성** | 소리 · 대사 속도 · 글자 크기 · 흔들림 · 판정 완화 |
| ⎋ **ESC 세로형 메뉴바** | 저장 · 불러오기 · 일기장 · 설정 · 타이틀 (사용자 요청) |
| 💾 **저장/불러오기 슬롯** | 한 페이지 가로 3 × 세로 2 = 6칸 (사용자 요청) |

사용자와 정한 방식

1. 엔딩 연출은 **대사 + 제목 카드 + 배경 한 장**
2. 뉴게임+는 **기록만 유지**, 능력치 계승 없음
3. 설정은 소리 3종 · 대사 · 접근성 3종
4. 크레딧은 한 장짜리 (정식 스태프롤은 74일차)

# Part 1. 엔딩 4종

71일차의 두 선택이 그대로 결말이 된다. 각 10줄, 12인의 후일담이 담긴다.

| 엔딩 | 조합 | 남는 것 |
| --- | --- | --- |
| **되돌아온 이름** | 관 끊음 + 이름 돌려줌 | 아르카이는 이름을 가진 채 잠들고, 사람들은 남은 침식과 함께 살기로 한다 |
| **마지막 침묵** | 관 끊음 + 벰 | 위협은 사라졌지만 무엇을 끝냈는지 아무도 부를 수 없다 |
| **잠든 이웃** | 관 유지 + 이름 돌려줌 | 세상은 안전해졌고, 세피라를 첫 순례자로 해마다 옥좌에 내려간다 |
| **다시 지워진 이름** | 관 유지 + 벰 | 천 년 전과 같은 선택. 기록실 벽에 「이름을 지우지 말 것」이 새겨진다 |

## 재생 흐름

```text
최종장 CH6_06 완료 → 로비 진입
      ↓
암전 → 별하늘(71일차 배경 재사용) → 엔딩 대사
      ↓
엔딩 제목 카드 (NEW ENDING 표시 · N회차 완료 · 본 엔딩 2/4)
      ↓
한 장짜리 크레딧 → [타이틀로]
```

- 같은 저장에서 두 번 재생되지 않는다 (`STORY_ENDING_PLAYED` 플래그)
- 일기장에 **「엔딩」 분류**를 새로 만들어 본 엔딩은 다시 볼 수 있다

# Part 2. 설정 · 접근성

| 분류 | 항목 |
| --- | --- |
| 소리 | 전체 음량 · 배경음 · 효과음 |
| 대화 | 대사 속도 (×0.50~×2.50) · 자동 진행 대기 (1~5초) |
| 접근성 | 글자 크기 (90~150%) · 화면 흔들림 줄이기 · 리듬 판정 완화 (+35%) |

설정은 저장 파일과 분리되어 회차가 바뀌어도 유지된다.

## 스토리 설정 통합 (추가 요청)

설정이 **두 군데**에 따로 있어, 새 설정창에서 대사 속도를 바꿔도 실제 대화는 바뀌지 않았다.

| | 대화 화면 ⚙ (Day62) | 설정창 (Day72) |
| --- | --- | --- |
| 저장 | `Dialogue.TextSpeed` 0~2 단계 | `Settings.DialogueSpeed` 배수 |
| 조작 | 느림 / 보통 / 빠름 | ◀ ×1.00 ▶ |

→ `DialogueSettings`를 **통합 설정을 읽는 얇은 다리**로 바꾸고, 값은 `GameSettings` 한 곳에만 두었다.

| 계산 | 식 |
| --- | --- |
| 초당 글자 수 | `45자 × 대사 속도` |
| 자동 넘김 대기 | `자동 진행 대기 + (0.035초 ÷ 대사 속도) × 글자 수` |

- 대화 화면의 전용 설정 창(느림/보통/빠름 버튼 6개)을 **삭제**하고, ⚙을 누르면 **같은 통합 설정창**이 열린다
- 글자 크기가 대사 본문(27) · 이름표(24) · 소속(16) · 선택지(24)에 실제로 적용된다

## 설정창 스크롤 (버그 수정)

줄을 **상자 높이의 비율로 위에서부터 빼는** 방식이라, 줄이 11개가 되자 합계가 1.0을 넘어 마지막 줄이 상자 밖으로 튀어나왔다.

→ 67일차 마을 패널과 같은 `ScrollRect` + `RectMask2D` + **픽셀 단위 쌓기**로 교체했다. 현재 내용 844px · 보이는 영역 620px이므로 224px만큼 내려서 본다. 값을 바꿔 다시 그려도 보던 위치가 유지된다.

# Part 3. ESC 세로형 메뉴바 (추가 요청)

화면 **왼쪽에 세로로 붙는 메뉴바**. ESC로 열고, ESC를 다시 누르거나 바깥을 클릭하면 닫힌다.

| 항목 | 동작 |
| --- | --- |
| 계속하기 | 닫기 |
| 저장하기 · 불러오기 | 슬롯 화면 |
| 일기장 | 로비에 있던 버튼을 옮겨 옴 |
| 설정 | 통합 설정창 |
| 타이틀로 나가기 | 타이틀 씬 |

- 사용 가능한 씬 : 로비 · 마을 · 상점 · 대장간 · 모험 지도 · 캐릭터 · 가방 · 파티 (타이틀 · 전투 · 결과 제외)
- **대사 · 이름 입력 · 놀이판이 떠 있으면 열리지 않는다**
- 69일차 규칙대로 `Keyboard.current.escapeKey` 사용

## 로비 버튼 정리

| 로비 버튼 | 처리 | 대체 |
| --- | --- | --- |
| 일기장 | 코드 삭제 | ESC → 일기장 |
| 저장 | 런타임 숨김 | ESC → 저장하기 |
| 타이틀 | 런타임 숨김 | ESC → 타이틀로 나가기 |

저장 · 타이틀 버튼은 `Lobby.unity`에 있고 `LobbyScreenController`가 참조하므로 숨김 처리만 했다. 완전히 지우려면 Unity에서 두 오브젝트를 삭제하면 된다(코드는 없어도 동작).

# Part 4. 저장 / 불러오기 슬롯 (추가 요청)

| 항목 | 내용 |
| --- | --- |
| 배치 | **한 페이지 가로 3 × 세로 2 = 6칸**, 총 **3페이지 18칸** (◀ 1/3 ▶) |
| 칸 왼쪽 위 | **칸 번호** `01`~`18` (금색) |
| 칸 오른쪽 위 | **저장 날짜 · 시간** `2026-09-12 14:03` |
| 칸 가운데 | 주인공 이름 · 일차/시간대 · 동료 수 · 최고 레벨 |
| 칸 아래 | 진행 중인 챕터, 오른쪽에 [비우기] |
| 빈 칸 | 어둡게 + "비어 있음" (불러오기 모드에서는 선택 불가) |

- 덮어쓰기 · 불러오기 · 비우기는 **확인 줄**에서 [예]/[아니오]를 거친다 (빈 칸 저장만 바로 실행)
- 슬롯에 저장하면 **이어하기용 파일도 같이 갱신**되어 타이틀 [이어하기]가 최신이 된다
- 목록은 전체 세이브를 읽지 않고 **필요한 값만 뽑아 읽는다** (18칸을 열어도 느리지 않게)
- `SaveData`에 `savedAtTicks`를 추가해 저장 시각을 기록한다

# Part 5. 타이틀 메뉴 (추가 요청) · 배치 버그

타이틀에 **[설정]** 버튼을 추가했다. 새 게임 · 이어하기 · 종료는 씬에 이미 있었고, 일기장은 63일차에 런타임으로 붙어 있었다.

## 처음 시도가 반영되지 않은 이유

씬을 조사해 보니 버튼들이 **앵커로만 배치**되어 있고 `anchoredPosition`은 전부 `(0, 0)`이었다.

| 버튼 | 앵커 y | anchoredPosition |
| --- | --- | --- |
| 새 게임 | 0.53 ~ 0.70 | (0, 0) |
| 이어하기 | 0.31 ~ 0.48 | (0, 0) |
| 종료 | 0.11 ~ 0.24 | (0, 0) |

위치값 차이로 한 칸 간격을 재는 방식이라 **간격이 0**으로 나왔고, 설정 버튼이 아예 배치되지 않았다. 같은 계산을 쓰던 63일차 일기장 버튼도 이동값이 0이라 **이어하기 버튼과 겹쳐** 있었다.

→ 위치값 계산을 버리고 **메뉴 전체를 앵커로 다시 배치**하는 방식으로 교체했다.

```text
새 게임    0.622 ~ 0.740
이어하기   0.481 ~ 0.600
일기장     0.341 ~ 0.459
설정       0.200 ~ 0.319
종료       0.060 ~ 0.178
```

일기장 패치와 설정 패치 **둘 다 마지막에 같은 `RelayoutMenu()`를 부르므로**, 어느 쪽이 먼저 실행되든 결과가 같다.

## 알아둘 점

- 타이틀 씬은 **앵커로 배치**되어 있다. `anchoredPosition`으로 위치를 계산하지 말 것 (전부 0이다)
- 타이틀 메뉴에 버튼을 더 붙이려면 `TitleMenuRuntimePatch.MenuOrder`에 이름을 넣고 `RelayoutMenu()`를 부르면 된다
- 설정 값은 전부 `GameSettings` 한 곳에 있다. 새 설정을 추가할 때 화면·기능 양쪽에 따로 저장하지 말 것
- 회차를 넘어 남겨야 하는 기록은 `PlayerProfile`(저장 파일 바깥), 한 회차 안에서만 쓰는 것은 `SaveData`에 둔다
- 줄이 늘어날 수 있는 패널은 처음부터 `ScrollRect` + 픽셀 쌓기로 만들 것. 비율 배치는 줄이 늘면 반드시 넘친다
