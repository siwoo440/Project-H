## 선택지가 갈리는 이야기

개인 1화는 중간에 선택지가 있고, 고른 쪽에 따라 서너 줄이 달라졌다가 다시 합쳐진다.

```
n1 → n2 → … → 선택지 ─┬─ a1 → a2 → a3 ─┬─ m1 → m2 → … → 끝
                      └─ b1 → b2 → b3 ─┘
```

CG 표시를 갈라진 줄(a · b)에 넣으면 다른 쪽을 고른 사람은 CG를 못 본다. 그래서 전부 **합쳐진 뒤의 줄(m)**에 넣었다.

28편 모두 선택지를 조합마다 따라가 보고, 어느 길로 가도 CG 줄을 지나는 것을 확인했다. 테스트도 같은 방법으로 검사한다.

## 대사 파일은 한 줄만 바뀌었다

대사 파일을 통째로 다시 쓰지 않고, 정한 줄 아래에 한 줄만 끼워 넣었다. 넣은 뒤에는 원래 내용과 비교해 **CG 표시 말고는 한 글자도 달라지지 않았는지** 확인했다.

## 특별한 밤 칸을 뺀 이유

이 이야기에는 그림을 그리지 않기로 했다. 칸을 남겨 두면 영영 빈 칸이다. 이야기 자체는 시나리오 목록에 그대로 있어 다시 볼 수 있다.

## 엔딩 칸은 새로 시작해도 열려 있다

보관함의 칸은 "그 이야기를 봤는가"로 열린다. 이 기록은 저장 파일에 있어서 새 게임을 시작하면 비워진다.

엔딩은 사정이 다르다. 엔딩을 봤다면 그 저장은 끝난 것이고, 다음에는 새 게임을 시작한다. 그러면 방금 본 엔딩 CG가 다시 잠긴다. 그래서 엔딩 칸만 **회차를 넘어 남는 기록**으로도 열리게 했다.
