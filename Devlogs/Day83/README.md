# Part 1. 공용 기능 — `UiSkinKit`

82일차의 `UiSkin.Apply`는 그림만 입힌다. 화면에 쓰려면 그림 말고도 함께 맞춰야 할 것이 있어서 한 겹을 더 만들었다.

| 함수 | 하는 일 |
| --- | --- |
| `Panel` | 스킨을 입히고, 상자 색 대신 그림 색을 쓰고, **코드로 그리던 외곽선을 끈다** |
| `Button` | `Panel` + 버튼 바로 아래의 **글자색을 바탕 밝기에 맞춘다** |
| `Toggle` | 선택됨 · 켬은 밝은 금색, 아님 · 끔은 어두운 청회색 **그림으로 교체** |
| `Glyph` | 글자 기호(`◀ ▶`)를 같은 색의 아이콘으로 |
| `LeadIcon` | `◀  로비` 같은 버튼을 아이콘 + `로비`로 |

스킨 파일이 없으면 모두 `false`를 돌려주고 아무것도 바꾸지 않는다. 화면은 예전 모습으로 돌아간다.

## 외곽선을 끄는 이유

지금까지 창의 테두리는 코드가 그리는 외곽선이었다. 그림에는 테두리가 이미 있어서, 외곽선을 그대로 두면 그림 전체가 네 방향으로 번져 겹쳐 보인다.

## 색 대신 그림으로 상태를 나타내는 이유

상점 탭은 선택된 탭의 **색**을 바꿔 표시했다. 그림 위에 색을 입히면 그림 색과 곱해져 흐려지고, 글자색은 그대로라 읽기 어려워진다. 그래서 선택 여부는 그림을 통째로 바꾸고 글자색도 함께 맞춘다.

# Part 2. 화면 7곳

## 적용 규칙

| 화면 계열 | 창 | 보통 버튼 | 눈에 띄는 버튼 |
| --- | --- | --- | --- |
| 어두운 화면 (글자가 흰색) | `panel_dark` | `button_tab_off` (어두운 청회색) | `button_primary` |
| 밝은 화면 (글자가 어두움) | `panel_light` | `button_secondary` (밝은 청회색) | `button_primary` |

어두운 화면의 글자는 흰색이라 버튼도 어두워야 읽힌다. `button_primary`(금빛 주황)는 양쪽에서 쓰되 글자를 어둡게 바꾼다.

## 화면별

| 화면 | 창 | 버튼 |
| --- | --- | --- |
| 설정 | 어두운 창 | 청회색 · 켬/끔은 그림 교체 · `◀ ▶`는 화살표 아이콘 |
| 저장/불러오기 | 어두운 창 · 저장 칸은 `slot`(빈 칸은 어둡게) | "예"는 주황 · "비우기"는 붉은 기 · 페이지 넘김은 화살표 |
| ESC 메뉴 | 어두운 창 | 청회색 · "타이틀로 나가기"는 붉은 기 |
| 전투 결과창 | 밝은 창 · 상단 띠는 `name_plate` · 보상 줄은 `panel_inset` · 동료 카드 · 체력 게이지 | "다음"은 주황 |
| 상점 | 상단 바 · 대사 상자와 상품 패널은 어두운 창 · 상품 카드는 `slot` | 탭은 그림 교체 · "구매"는 주황 · 뒤로 버튼에 아이콘 |
| 모험 지도 | 상단 바 · 지역 패널은 어두운 창 · 던전 카드는 `slot`(잠긴 던전은 어둡게) | "탐험 시작"은 주황 · 뒤로 버튼에 아이콘 |
| 가방 | 밝은 창 3개 · 목록 바탕은 `panel_inset` · 아이템 칸은 `card` | "사용"은 주황 · 뒤로 버튼에 아이콘 |

## 손이 더 간 곳

- **전투 결과창** : 상단의 남색 띠가 창 전체 너비였다. 새 창은 모서리가 둥글어서 띠의 네모난 모서리가 밖으로 삐져나온다. 띠를 창 테두리 안쪽으로 조금 줄이고, 뒤에 깔던 그림자 상자는 숨겼다
- **모험 지도의 던전 카드** : 선택한 카드의 금테는 그대로 남겼다. 스킨을 먼저 입히고 그 뒤에 금테가 붙는 순서라 꺼지지 않는다
- **쓰러진 동료 카드** : 예전에는 외곽선 색으로 구분했다. 외곽선이 꺼지므로 카드에 옅은 붉은 기를 입힌다

## 알아둘 점

- **창 · 버튼 그림은 `UiSkinKit`으로 입힐 것.** 외곽선 끄기와 글자색 맞춤이 함께 들어 있다
- **버튼 색을 직접 바꿔 "선택됨"을 나타내지 말 것.** 그림 위에서는 보이지 않는다. `UiSkinKit.Toggle`을 쓴다
- **`UiSkinKit.Button`은 글자를 만든 뒤에 부를 것.** 버튼 바로 아래의 글자만 색을 맞춘다. 카드처럼 글자가 여러 개인 버튼은 `Panel`을 쓴다
- 어두운 화면의 버튼은 `button_tab_off`, 밝은 화면은 `button_secondary`
