# Part 1. 색이 뜻을 가진 곳을 다루는 방법

## 문제

지금까지 화면은 상자의 색을 바꿔 상태를 알렸다. 그림 위에서는 색이 그림과 **곱해진다.** 예전의 어두운 상자 색을 그대로 넣으면 그림이 까맣게 죽는다.

## 세 가지 방법

| 색의 뜻 | 방법 | 함수 |
| --- | --- | --- |
| 고른 탭 · 켬/끔 | 그림을 통째로 바꾼다 | `Toggle` (83일차) |
| 고른 카드 · 닫힌 칸 | 그림은 두고 옅은 기만 입힌다 (금빛 · 어둡게) | `SetSelected` · `SetState` |
| 버튼의 종류 (초록 = 새 동료, 갈색 = 놀이판) | 원래 색을 밝고 옅게 바꿔 입힌다 | `Hint` |

`SetState`는 스킨이 입혀진 그림인지 먼저 본다. 스킨 파일이 없어 색 상자로 남은 경우에는 예전 색을 그대로 넣는다. 그래서 그림이 없어도 화면이 예전처럼 동작한다.

# Part 2. 화면별

| 화면 | 창 | 버튼 · 상태 |
| --- | --- | --- |
| 마을 | 상단 바 · 구역 카드는 `slot` · 행동 패널은 어두운 창 | 시간을 쓰는 행동은 주황 · 나머지는 원래 색을 옅게 · 닫힌 구역은 어둡게 |
| 노드 던전 | 지도 패널과 팝업은 어두운 창 | "탐험 포기"는 붉은 기 |
| 대장간 | 상단 바 · 대사 상자 · 작업대 · 장비 목록은 어두운 창 · 장비 카드는 `slot` | 강화/초월 탭과 주문서 등급은 그림 교체 · "강화하기"는 주황 · 고른 장비는 금빛 |
| 그림 보기 창 | 질문 상자는 밝은 창 | "네"는 주황 · 닫기에 아이콘 |

- 마을 구역 카드는 뒤의 마을 그림이 살짝 비치도록 투명도를 조금 남겼다
- 노드 던전의 노드 색(전투 · 보물 · 함정)은 그 자체가 정보라서 건드리지 않았다

## 일기장은 책 모양을 유지

일기장은 가죽 표지 · 종이 · 책갈피로 된 **책 모양**이 이미 잡혀 있다. 선택한 책갈피가 종이색이 되어 페이지와 이어지는 것도 그 디자인의 일부다. 남색 · 금색 창을 덮으면 이 모양이 깨진다.

→ 창과 책갈피는 그대로 두고 **글자 기호만 아이콘으로** 바꿨다 (닫기 · 쪽 넘김).

# Part 3. 로비

## 내비 아이콘 — `LobbyNavIcons`

하단 버튼은 글자만 있었다. 버튼 위쪽에 아이콘을 올리고 글자는 아래로 내렸다.

| 버튼 | 아이콘 |
| --- | --- |
| 모험 · 캐릭터 · 파티 | 지도와 나침반 · 인물 · 깃발 |
| 가방 · 상점 · 대장간 · 마을 | 가방 · 동전 주머니 · 모루 · 집 |

버튼의 **글자**를 보고 아이콘을 고른다. 로비 버튼은 씬에 놓인 것(3개)과 코드가 나중에 붙이는 것(4개)이 섞여 있어서, 모두 만들어진 뒤인 첫 프레임에 한 번 올린다.

## 골드 아이콘

로비와 파티 화면의 골드 옆에 금화를 넣었다. 아이콘이 있으면 "골드" 글자 없이 숫자만 보여 준다.

# Part 4. 아이템 칸

상점 · 가방 · 대장간의 아이템 칸은 "등급 색 상자 + 안쪽 어두운 칸"을 겹쳐 테두리처럼 보이게 하던 것이다. 이것을 은테 칸 그림 한 장으로 바꿨다.

등급 색은 그림의 은색 테두리에 입힌다. 등급 색은 원래 어두운 편이라 그대로 곱하면 테두리가 바탕에 묻힌다. **흰색과 섞어 밝게** 만든 뒤 입힌다.

## 알아둘 점

- **상태에 따라 색을 바꾸는 곳은 `UiSkinKit.SetState` · `SetSelected`를 쓸 것.** 그림 위에 예전의 진한 상자 색을 넣으면 그림이 까맣게 죽는다
- **색이 뜻을 가진 버튼은 `UiSkinKit.Hint`로 색감을 남길 것**
- 일기장은 책 모양이 디자인이라 스킨을 입히지 않았다
- 로비 내비 아이콘은 버튼의 글자로 고른다. 버튼 글자를 바꾸면 `LobbyNavIcons`의 대응표도 바꿔야 한다
