# 프로젝트 H : 57일차 개발 로그

57일차는 Phase 3 두 번째 콘텐츠인 **선물 시스템**을 만들었다.

Day56에서 호감도 단계마다 보상을 붙였지만, 정작 호감도를 올리는 방법은 캐릭터 창의 디버그 버튼(±10)뿐이었다. 이번에 **게임 안에서 호감도를 올리는 첫 수단**을 넣었다.


## 1. 선물 아이템 6종

`ItemType.Gift`(값 3)는 Day2부터 열거형에만 있고 쓰이지 않던 유형이다. 이번에 처음으로 실제 에셋을 만들었다.

| ID | 이름 | 등급 | 구매 | 판매 |
| --- | --- | --- | --- | --- |
| `IT_GIFT_FLOWER` | 들꽃 꽃다발 | 일반 | 60 | 24 |
| `IT_GIFT_CANDLE` | 성수 향초 | 고급 | 80 | 32 |
| `IT_GIFT_BROOCH` | 기사단 문장 브로치 | 희귀 | 150 | 60 |

- 에셋 6개와 `.meta`를 `Data/Items/`에 만들고, Day46에서 정리한 대로 **`ProjectHDataCatalog.asset`에 GUID를 등록**했다. 등록하지 않으면 `DataManager`가 아이템을 찾지 못한다
- 로비 상점(`SHOP_LOBBY`)에 `PRD_GIFT_*` 상품 6개를 추가했다. 판매가는 기존 물약과 같은 **구매가의 40%**다
- 가방은 장비가 아닌 아이템을 모두 보여주므로 별도 수정 없이 선물이 표시된다

### 상점 화면 2열 배치

상점 화면은 상품을 **최대 6개까지만** 그리도록 되어 있었다(Day40). 선물을 넣으면 상품이 10개가 되어 4개가 잘린다. 상품이 **6개를 넘으면 2열**로 배치하고, 행이 많아지면 간격을 좁히도록 바꿨다. 6개 이하일 때는 기존 1열 배치 그대로다.

## 2. 취향 표

`GiftPreferenceCatalog` 한 파일에서 취향과 수치를 조정한다. Day56 보상표처럼 에셋이 아닌 **코드 목록**이다.

| 취향 | 호감도 |
| --- | --- |
| 아주 좋아함 | **+15** |
| 좋아함 | +8 |
| 보통 | +4 |
| 별로 | +1 |

**표에 없는 조합은 모두 보통**이다. 그래서 12명 × 6종 = 72칸을 다 채우지 않아도 되고, 이번에는 초기 4인의 취향만 정했다.

| 캐릭터 | 아주 좋아함 | 좋아함 | 별로 |
| --- | --- | --- | --- |
| 세레나 | 성수 향초 | 들꽃 꽃다발 | 브로치 |
| 엘렌 | 기사단 문장 브로치 | 달콤한 과자 | 들꽃 꽃다발 |
| 릴리아 | 별자리 지도 | 성수 향초 | 정령의 조개 |
| 이브 | 정령의 조개 | 달콤한 과자 | 성수 향초 |

'별로' 칸은 Day52 속성과 맞췄다. 불 속성 릴리아는 물의 조개를, 물 속성 이브는 불을 켜는 향초를 반기지 않는다. '별로'여도 호감도가 **깎이지는 않고** +1만 오른다. 선물을 샀는데 손해를 보는 경험은 피하고 싶었다.

## 3. 하루 선물 제한

골드만 있으면 하루 만에 호감도를 100으로 만들 수 있으면 곤란하다. **캐릭터당 하루 3회**로 제한했다.

`CharacterSaveData`에 두 필드를 추가했다.

```csharp
[SerializeField] private int lastGiftDay;      // 마지막으로 선물한 일차
[SerializeField] private int giftsGivenToday;  // 그날 받은 선물 횟수
```

날짜가 바뀔 때 모든 캐릭터의 횟수를 지우는 대신, **선물할 때 날짜를 비교**한다.

```csharp
public int GetGiftsGivenToday(int currentDay)
{
    return lastGiftDay == currentDay ? giftsGivenToday : 0;   // 날짜가 다르면 0회
}
```

이렇게 하면 Day41의 시간 진행 코드(`GameTimeService.AdvanceTime`)를 건드리지 않아도 된다. 필드가 없던 기존 세이브는 0(선물 기록 없음)으로 시작하므로 **예전 저장 파일도 그대로 열린다.**

제한은 캐릭터별이다. 세레나에게 3번 줬어도 엘렌에게는 따로 3번 줄 수 있다.

## 4. 선물 처리 — `GiftService`

```csharp
public static bool TryGive(SaveData save, DataManager data, string characterId, string itemId, out GiftResult result)
```

**먼저 모든 조건을 검사**하고, 하나라도 걸리면 **아무것도 바꾸지 않고** 거부한다.

| 순서 | 검사 | 거부 문구 |
| --- | --- | --- |
| 1 | 캐릭터 보유 | 선물할 캐릭터를 찾을 수 없습니다 |
| 2 | 선물 유형 아이템 | 선물할 수 없는 아이템입니다 |
| 3 | 호감도 100 미만 | 호감도가 이미 최대입니다. 선물은 아껴 두세요 |
| 4 | 오늘 3회 미만 | 오늘은 더 이상 선물할 수 없습니다 (3/3) |
| 5 | 가방에 1개 이상 | 가방에 ○○이(가) 없습니다 |

통과하면 순서대로 처리한다.

1. 가방에서 1개 차감 (`ItemInventoryService.TryRemove`)
2. 취향에 따라 호감도 증가 (100에서 멈춤)
3. 오늘 선물 횟수 +1
4. 취향 발견 플래그 기록
5. 새로 도달한 단계 계산

호감도가 100일 때 거부하는 이유는, 선물을 받아도 오를 호감도가 없는데 아이템만 사라지기 때문이다. 95에서 +15 선물을 주면 **실제로 오른 5만** 결과에 표시한다.

### 결과 — `GiftResult`

| 항목 | 용도 |
| --- | --- |
| `Preference` · `AffinityGain` | 취향과 실제 증가량 |
| `GiftsGivenToday` | 오늘 n/3 |
| `DiscoveredPreference` | 이번에 취향을 처음 알게 됐는지 |
| `NewTiers` | 이번 선물로 넘어선 단계 목록 |
| `Message` | 화면에 그대로 띄우는 안내 문구 |

```text
성수 향초 선물 · 아주 좋아함 (새 취향 발견!) · 호감도 +15 (25/100) · 오늘 1/3
안면 단계 도달! [호감도 보상]에서 보상을 받으세요.
```

## 5. 취향 발견 — 스토리 플래그

처음에는 모든 취향이 **`?`**로 보이고, **한 번 선물해야** 그 캐릭터의 취향을 알게 된다.

```text
SYS_GIFT_KNOWN:CH_SERENA:IT_GIFT_CANDLE
```

Day56의 호감도 보상 기록은 전투 스탯 계산 때문에 `CharacterSaveData` 안에 비트로 넣었지만, 취향 발견은 **화면 표시에만 쓰이는** 정보다. 그래서 골드(Day40)처럼 기존 스토리 플래그를 재사용했다. 저장 구조를 늘리지 않아도 되고, Day56 이벤트 조건(`GameEventCondition.Flag`)으로 "세레나의 취향을 알아낸 뒤" 같은 조건도 바로 걸 수 있다.

`SetStoryFlag`가 새로 추가됐을 때만 `true`를 돌려주므로, 그 값을 그대로 "처음 발견"으로 쓴다.

## 6. Day56 호감도 보상 연계

선물로 단계를 넘으면 결과 문구로 알려주고, 선물 패널 하단에 **`받을 수 있는 호감도 보상이 있어요 ▶`** 버튼이 나타난다. 누르면 선물 패널이 닫히고 호감도 보상 패널이 열린다.

바로가기 버튼은 "방금 넘은 단계"가 아니라 **받기 상태인 보상이 하나라도 있는지**로 표시한다. 선물 패널을 닫았다 열어도, 캐릭터를 바꿔도 안내가 사라지지 않는다.

## 7. 선물하기 패널 — `CharacterGiftPanel`

Day56 최적화 때 호감도 보상 패널을 `CharacterAffinityRewardPanel`로 분리해 둔 덕분에, 같은 구조로 새 패널을 만들어 붙이기만 하면 됐다.

```text
┌ 세레나 · 선물하기   (안면 25/100)                  [닫기] ┐
│ DAY 3 · 오늘 선물 1/3                                     │
│ [들꽃 꽃다발  보유 2 ]   [성수 향초  보유 1  ]            │
│ [취향 : ?            ]   [취향 : 아주 좋아함 (+15)]       │
│ [기사단 문장 브로치 ...] [별자리 지도 ...    ]            │
│ [정령의 조개 ...     ]   [달콤한 과자 ...    ]            │
│ 취향 : 아주 좋아함 +15 · 좋아함 +8 · 보통 +4 · 별로 +1    │
│ [테스트 선물 지급]      [받을 수 있는 호감도 보상이 있어요 ▶] │
│ 결과 문구                                                 │
└──────────────────────────────────────────────────────────┘
```

- 캐릭터 창 하단, `호감도 보상` 오른쪽에 **`선물하기`** 버튼 추가
- 선물 버튼은 **보유 중일 때만** 누를 수 있다. 하루 제한이나 최대 호감도일 때는 버튼을 막지 않고, 눌렀을 때 **거부 사유를 보여준다**
- 알게 된 취향은 버튼 색으로 구분한다: 아주 좋아함 분홍 · 좋아함 연두 · 보통 베이지 · 별로 회청 · 모름 회색
- 호감도 보상 패널과 선물 패널은 **동시에 열리지 않는다**
- **`테스트 선물 지급`**(6종 1개씩)은 Day56 `DevelopmentFeatures.HideInRelease()`로 출시 빌드에서 숨긴다
