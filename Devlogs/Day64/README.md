# 프로젝트 H : 64일차 개발 로그

## 오늘 목표

64일차는 **추가 캐릭터 8인을 실제로 쓸 수 있게 만들어 12인 파티를 완성**했다. 이전에는 캐릭터 에셋과 프로필만 있고 스킬은 임시 이름("노엘 스킬 1"), 궁극기는 없는 상태였다.

| 캐릭터 | 역할 | 속성 | 합류 조건 (임시) |
| --- | --- | --- | --- |
| 클레어 | 연금술사 · 만능 지원 | 풀 | 숲(무너진 성역의 숲) 클리어 |
| 메르시아 | 무도승 · 순간 폭딜/속박 | 풀 | 숲 클리어 |
| 파이라 | 창기사 · 공격형 브레이커 | 불 | 늪지대(침식된 회랑) 클리어 |
| 티리아 | 방패병 · 보호막 탱커 | 무 | 늪지대 클리어 |
| 노엘 | 탐험가 · 함정/둔화 CC | 물 | 마왕성(심연의 관문) 도전 |
| 루시아 | 총사수 · 방어 무시 저격 | 불 | 마왕성 도전 |
| 나타샤 | 잠입자 · 출혈/암살 | 어둠 | 마왕성 도전 |
| 세피라 | 순례자 · 공격+회복+부활 | 빛 | 마왕성 도전 |

사용자와 정한 방식(추천안)

1. 합류는 **던전 진행 조건 → 마을 길드 합류 이벤트**. 68~69일차 스토리 챕터가 생기면 챕터 합류로 교체한다
2. 대사는 **합류 이야기 1편 + 시간대 일상 대화 4편**씩. 개인 · 결속 · 마을 · 여관 이야기는 70일차
3. 스킬 · 궁극기 수치는 기획서 역할 기준 **임시값**, 67일차 1차 밸런스에서 조정
4. 이미 조건을 채운 기존 세이브는 길드에 들어가면 바로 합류 소식이 뜬다

기획서 참고 범위: 캐릭터 상세 시트(5~12번 캐릭터)의 스킬 · 궁극기 · 성격 · 말투 · 출신

# Part 1. 전투 — 새 효과 9종

8인의 스킬을 데이터로 표현하려고 스킬 효과 종류를 늘렸다. 모두 기존 효과 실행기(`BattleSkillEffectExecutor`)에서 동작하고, 상태 아이콘 · 정화 · 버프 제거 규칙을 그대로 따른다.

| 효과 | 종류 | 동작 | 쓰는 캐릭터 |
| --- | --- | --- | --- |
| 공격력 증가 | 버프 | 공격 배율 +N% | 클레어 · 메르시아 · 세피라 |
| 공격 속도 증가 | 버프 | 공속 +N% | 루시아 |
| 둔화 | 약화 | 공속 −N% | 클레어 · 노엘 |
| 보호막 | 보호 | **시전자** 최대 체력 N% 보호막 | 티리아 |
| 방어 감소 (신규 상태 "깎") | 약화 | 방어력 −N% (최대 90%) | 루시아 · 파이라 · 노엘 · 메르시아 |
| 공격 감소 (신규 상태 "약") | 약화 | 공격 배율 −N% | 세피라 |
| 버프 제거 | 특수 | 남은 시간이 긴 버프부터 N개 제거 (전투 내내 유지되는 버프는 제외) | 나타샤 |
| 저체력 추가 피해 | 피해 | 시전자 체력 50% 이하일 때만 추가 피해 | 나타샤 |
| 부활 | 특수 | 쓰러진 아군 N명을 체력 N%로 부활 | 세피라 |

- 공격 배율은 `(1 + 증가) × (1 − 감소)`, 방어력은 `기본 × (1 + 증가) × (1 − 감소)`로 계산한다
- 효과 목록 실행을 `ExecuteEffects`로 분리해 **스킬과 궁극기가 같은 실행기**를 쓴다

# Part 2. 합류 시스템

```text
[마을 지도]                          [마을 · 길드]
┌ 길드 ──────────────┐              ┌ 행동 패널 ─────────────────────┐
│ 길드                │              │ 길드                           │
│ 의뢰와 모험의 시작   │   들어가기    │ [★ 새 동료 소식 · 클레어 (외 1명)] │ ← 합류 이야기
│ ★ 새 동료 소식 2건   │  ─────────▶  │ [전원 합류 (개발용)]              │ ← 에디터·개발 빌드만
│ ● 엘렌              │              │ [의뢰 게시판]                    │
└────────────────────┘              │ [모험 떠나기 (던전 선택)]         │
                                     └────────────────────────────────┘
```

| 단계 | 내용 |
| --- | --- |
| 1. 조건 | 숲 클리어 · 늪지대 클리어 · **마왕성 도전**(입장만 해도 인정, 클리어해도 인정) |
| 2. 소식 | 길드 지도 카드에 "★ 새 동료 소식 N건", 길드 안에 첫 동료 버튼 (여러 명이면 차례로) |
| 3. 합류 | 합류 이야기를 **끝까지 보면** 레벨 1로 합류 + 선택지 호감도. 중간에 닫으면 합류하지 않음 |
| 4. 이후 | 파티 편성 · 캐릭터 창 · 마을 배치 · 대화 · 선물에 바로 등장 |

- 던전 입장에 성공하면 `DUNGEON_ENTERED_{던전 ID}` 스토리 플래그를 남긴다(무료 · 유료 입장 모두)
- 새 동료는 `SaveData.AddCharacterInternal`로 추가하며, 이미 있으면 추가하지 않는다
- 개발용 [전원 합류]는 조건 · 이야기 없이 8인을 바로 합류시킨다(출시 빌드에서는 숨김)
- 새 8인은 마을 이벤트 · 여관 대사가 아직 없어서, 해당 버튼이 꺼지고 "이 동료와의 이야기는 준비 중이에요 (70일차 개인 스토리에서 추가)"라고 안내한다. 결속 대사도 파일이 없으면 넘어간다(기존 동작)
