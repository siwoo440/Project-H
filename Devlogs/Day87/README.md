# Part 1. 규칙

| 단계 | 이름 | 조건 |
| --- | --- | --- |
| 1단계 | 의상 손상 | 체력이 60% 이하로 **내려가는 순간** |
| 2단계 | 의상 파괴 | 체력이 30% 이하로 **내려가는 순간** |

"체력이 낮은 동안 계속"이 아니라 "문턱을 넘는 순간"에 한 번 나온다.

## 한 번만 나온다

| 상황 | 결과 |
| --- | --- |
| 회복했다가 다시 60% 아래로 | 다시 나오지 않는다 |
| 한 방에 100% → 20% | 2단계만 나온다. 1단계는 나중에도 나오지 않는다 |
| 한 방에 쓰러짐 | 나오지 않는다 (쓰러짐 연출이 따로 있다) |
| 부활로 체력이 오름 | 나오지 않는다. 그 뒤에 맞아서 내려가면 나온다 |
| 다음 전투 | 처음부터 다시 |

회복과 부활을 걸러내는 방법은 단순하다. **이전보다 체력이 줄었을 때만** 단계를 본다.

## 여러 명이 한꺼번에 맞으면

광역 공격으로 네 명이 동시에 문턱을 넘을 수 있다. 그림은 한 명씩 차례로 나온다.

- 온 순서대로 나온다
- 같은 캐릭터의 1단계가 기다리는 중에 2단계가 되면 **2단계 하나로 합친다**
- 뒤에 기다리는 그림이 있으면 머무는 시간이 1.1초에서 0.6초로 줄어든다

## 능력치는 바뀌지 않는다

연출만 있다. 전투 계산 코드는 건드리지 않았고, 이미 있던 "체력이 바뀌었다"는 신호를 듣기만 한다.

# Part 2. 화면

## 자리

전투 화면에서 비어 있는 곳은 왼쪽 끝뿐이다.

```
┌──────────────────────────────────────────────┐
│[웨이브]        [ 보스 체력바 ]     [배속][메뉴] │
│┌──────┐                                      │
││      │                                      │
││ 의상 │   아군 4명            적              │
││ 파괴 │                                      │
││ 그림 │                                      │
│└──────┘                                [자동] │
│[카드][카드][카드][카드]   [ 스킬 블록 판 ]      │
└──────────────────────────────────────────────┘
```

| | 값 |
| --- | --- |
| 가로 | 화면의 0 ~ 19% |
| 세로 | 화면의 24.5 ~ 90.5% |
| 1920×1080에서 | 약 365×713픽셀 |

위로는 웨이브 표시, 아래로는 HUD 카드와 겹치지 않고, 오른쪽으로는 맨 왼쪽 아군(중심이 약 26%)보다 왼쪽이다.

## 전신이 보이게 넣었다

대화 화면은 스탠딩을 확대해 무릎 위만 보여 준다. 여기서는 **전신**을 넣었다. 옷자락 끝과 신발까지 보여야 손상이 드러나기 때문이다.

화면을 직접 볼 수 없어서, 실제 그림을 틀 크기에 맞춰 합성해 배율 1.0 · 1.2 · 1.4를 비교하고 정했다. `OutfitBreakView.ArtScale` 숫자 하나로 바꿀 수 있다.

## 움직임

| 구간 | 시간 | 모습 |
| --- | --- | --- |
| 들어옴 | 0.22초 | 왼쪽 화면 밖에서 빠르게 들어와 멈춘다 |
| 번쩍임 | 0.30초 | 도착하는 순간 하얗게 번쩍인다 |
| 머묾 | 1.10초 | 이름표에 `세레나 · 의상 파괴` |
| 나감 | 0.28초 | 옅어지며 왼쪽으로 빠진다 |

합쳐서 1.6초다. 전투 배속을 올려도 이 시간은 같다.

## 전투를 끊지 않는다

이 게임의 전투는 실시간이고, 스킬 블록과 리듬 판정을 계속 조작해야 한다. 그림이 뜰 때마다 조작이 끊기면 곤란하다.

| 지킨 것 | 방법 |
| --- | --- |
| 전투가 멈추지 않는다 | 전투 시간을 건드리지 않는다 |
| 클릭을 막지 않는다 | 클릭 판정(GraphicRaycaster)이 없는 Canvas |
| 궁극기 컷인 · 리듬 판정과 겹치지 않는다 | 전투가 멈춘 동안에는 그림도 그대로 기다린다 |
| 결과창 뒤에 남지 않는다 | 전투가 끝나면 대기 중인 그림까지 버린다 |

## 끌 수 있다

설정 창에 **전투 > 의상 파괴 연출** 항목을 넣었다. 기본은 켬이다.

꺼 둔 동안에도 "이미 지나간 단계"는 기록한다. 전투 도중에 켰을 때 지난 단계가 뒤늦게 나오지 않게 하기 위해서다.

# Part 3. 그림

## 요청

| 항목 | 내용 |
| --- | --- |
| 장수 | 12명 × 2단계 = 24장 |
| 규격 | 스탠딩과 같은 1024×1536, 투명 배경 |
| 자세 | 기본 스탠딩과 같은 자세 · 같은 머리 위치 |
| 1단계 | 옷자락과 소매 끝이 조금 해짐, 먼지와 그을음, 이를 악문 표정 |
| 2단계 | 망토와 소매가 크게 찢어짐, 갑옷에 금, 한쪽 눈을 찡그린 표정 |

기본 스탠딩과 같은 자세로 받은 이유는 두 가지다. GPT가 기존 그림을 고치는 방식으로 그릴 수 있어 캐릭터가 달라 보이지 않고, 틀 안의 구도를 스탠딩 기준으로 한 번만 잡으면 된다.

## 수위

"전투로 해진 옷"까지로 정했다. 손상은 겉옷 · 망토 · 소매 · 옷자락 끝 · 갑옷 · 장신구에만 있고, 몸통을 가리는 옷은 그대로다. 특별한 밤 이벤트와 같은 기준이다.

## 받은 그림 확인

| 확인한 것 | 결과 |
| --- | --- |
| 장수 · 이름 | 24장 모두 있음 |
| 크기 · 형식 | 전부 1024×1536, 투명 배경 |
| 머리 · 발 위치 | 머리 꼭대기 25~26, 발끝 1510 |
| 자세 | 기본 스탠딩과 같음 |
| 내용 | 24장을 기본 스탠딩과 나란히 놓고 한 장씩 확인 |

## 그림이 없어도 동작한다

그림을 찾는 순서를 이렇게 두었다.

```
그 단계의 전용 그림 → 아래 단계의 전용 그림 → 스탠딩 표정 → 없으면 건너뜀
```

그림이 오기 전에는 스탠딩의 놀란 얼굴(1단계)과 슬픈 얼굴(2단계)이 대신 나왔다. 덕분에 그림을 기다리지 않고 기능을 먼저 만들 수 있었고, 그림을 넣을 때 코드는 고칠 것이 없었다.

## 알아둘 점

- **전투 중에 뜨는 연출은 입력을 막지 말 것.** 클릭 판정이 없는 Canvas를 쓰고 전투 시간을 멈추지 않는다
- 문턱은 `OutfitBreakRules.LightThreshold` · `HeavyThreshold`, 자리와 크기는 `OutfitBreakView.FrameMin` · `FrameMax` · `ArtScale`, 시간은 `OutfitBreakTimeline`의 상수다
- 스탠딩의 자세나 비율을 바꾸면 의상 파괴 그림 24장도 함께 다시 받아야 한다
