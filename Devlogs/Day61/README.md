# 프로젝트 H : 61일차 개발 로그

## 오늘 목표

61일차는 사용자 목업을 반영해 재편한 일정의 첫 날로, 세 가지를 한 번에 진행했다.

1. **대장간 씬** — 강화 주문서 · 성공 확률 · 대장장이 NPC가 있는 강화 작업대, 장비 강화 +0~+5 · 초월 ★1~★3
2. **상점 UI 개편** — 목업대로 왼쪽 상점 주인 · 대사, 오른쪽 탭 + 4열 카드. 오늘의 상품 · 하루 재고 · 품절 · 리롤
3. **경제 밸런스** — 던전 입장에 활력 소비, 던전 골드 보상 조정

추가 요청으로 로비 하단의 미사용 **로비 · 메뉴** 버튼을 지우고, **상점 왼쪽 칸에 대장간 버튼**을 만들었다(상점 안의 대장간 버튼은 제거).

기획서 참고 범위: 탭 2의 7장 상점(일자 갱신 · 재고 제한 · 리롤 · 품절 · 예외 처리 7.11) · 장비 강화 표(+0→+5 500~2,500G) · 장비 초월(1⭐→2⭐ 20,000G, 2⭐→3⭐ 30,000G) · 8.12 룬 슬롯. 8장 대장간과 9장 마을은 기획서에 제목만 있어서 목업을 기준으로 구성했다.

# Part 1. 장비 강화 · 초월

## 1. 강화 +0 → +5

장비에 **강화 주문서 1장 + 골드**를 쓰면 한 단계씩 올라간다. 단계마다 장비 옵션이 **+10%** 오른다.

| 단계 | 골드 | 기본 성공 확률 (C 주문서) |
| --- | --- | --- |
| +0 → +1 | 500G | 100% |
| +1 → +2 | 1,000G | 100% |
| +2 → +3 | 1,500G | 90% |
| +3 → +4 | 2,000G | 75% |
| +4 → +5 | 2,500G | 60% |

- **실패해도 장비는 부서지거나 단계가 내려가지 않는다.** 주문서만 사라지고 골드는 성공했을 때만 낸다
- 실패할 때마다 다음 성공 확률이 **+10%p** 쌓이고(기획서 "보정치 누적"), 성공하면 초기화된다
- 주문서가 맞지 않거나 골드가 모자라면 **아무것도 소모하지 않고** 거부한다

## 2. 강화 주문서 6종

| 주문서 | 대상 | 확률 보너스 | 구하는 법 |
| --- | --- | --- | --- |
| 무기 강화 주문서 C | 무기 | +0% | 상점 상시 150G · DG001~004 드롭 |
| 무기 강화 주문서 B | 무기 | +15%p | 오늘의 상품 400G · DG003~004 드롭 |
| 무기 강화 주문서 A | 무기 | +30%p | 오늘의 상품 1,000G |
| 방어구 강화 주문서 C | 투구 · 방어구 · 장갑 · 신발 | +0% | 상점 상시 120G · DG001~004 드롭 |
| 방어구 강화 주문서 B | 〃 | +15%p | 오늘의 상품 350G · DG003~004 드롭 |
| 방어구 강화 주문서 A | 〃 | +30%p | 오늘의 상품 900G |

목업의 "C" 표기를 등급으로 해석했다. 주문서는 일반 재료 아이템(ItemData)이라 카탈로그 GUID 등록만으로 상점 · 드롭 · 가방에서 그대로 쓰인다.

## 3. 초월 ★1 → ★3

| 초월 | 재료 | 기본 능력치 |
| --- | --- | --- |
| ★1 (기본) | — | ×1.0 |
| ★1 → ★2 | **+5 장비** + 같은 장비 1개(미장착) + 20,000G | ×1.5 |
| ★2 → ★3 | **+5 장비** + 같은 장비 1개(미장착) + 30,000G | ×2.0 |

- 초월하면 강화 단계가 **+0으로 돌아간다**(기획서 "초월 시 강화 단계 초기화"). 대신 기본 능력치가 올라, 다시 +5까지 올리면 더 강해진다
- 최종 배율 = **초월 배율 × (1 + 0.1 × 강화 단계)**. 최대인 ★3 +5는 **3배**다
- 재료는 같은 장비 중 **강화 · 초월이 가장 낮은 미장착 장비**를 자동으로 고른다. 장착 중인 장비는 재료가 되지 않는다
- 이름은 「철제 검 +3 ★2」처럼 표시된다(★1은 생략). 캐릭터 창의 장비 칸 · 목록 · 상세도 같은 규칙을 쓴다

## 4. 전투 · 룬 반영

- `BattleEquipmentStatCalculator`가 장비 옵션을 더할 때 **강화 · 초월 배율을 곱한다**. 이 계산을 쓰는 곳(전투 · 캐릭터 창 · 장비 비교)이 모두 자동으로 반영된다. 테스트: 철제 검 공격력 35 → +5에서 52.5
- **룬 5번 칸 해금 조건**을 Day60의 임시 조건 "결속 5단계"에서 **★2 이상 초월 장비 착용**으로 바꿨다. 기획서의 "전용 장비 초월"은 Day70 전용 장비와 연결한다
- 저장: `EquipmentInstanceSaveData`에 강화 단계 · 초월 단계 · 연속 실패를 추가했다. **기존 세이브 장비는 +0 ★1**로 읽는다

# Part 2. 대장간 씬

```text
[◀ 로비]  대장간                                   ● 12,345 G
┌ 작업대 ─────────────────────────┐   ┌ 장비 선택 (또는 대장장이) ┐
│ [강화][초월]          [장비 선택] │   │  [카드][카드][카드][카드]  │
│ ┌초상┐   [장비 칸]  +  [주문서]  │   │  [카드][카드][카드][카드]  │
│ │    │   철제 검 +2   ×3 [C][B][A]│   │  ◀ 1/1 ▶        [닫기]   │
│ 세레나 장착 중                   │   └──────────────────────────┘
│        +2   >>>   +3             │   ┌ 브론 · 대장장이 ─────────┐
│ 강화 내용  공격력 +42 → +45.5    │   │ 좋아, 잘 먹혔군!          │
│ 성공 확률 90%     ● 1,500G · 1장 │   │ 강화 성공! 철제 검 +3     │
│          [ 강화하기 ]            │   └──────────────────────────┘
```

| 영역 | 내용 |
| --- | --- |
| 진입 | 로비 하단 **[대장간]** 버튼(상점 왼쪽 칸) · 뒤로 [◀ 로비] |
| 작업대 | 강화/초월 탭 · 장착자 초상(상반신) · 장비 칸 · 주문서(초월은 재료 장비) 칸과 보유 수 · C/B/A 선택 · 「+N >>> +N+1」 · 능력치 변화 · 성공 확률(실패 보정 표시) · 비용 · [강화하기]/[초월하기] |
| 오른쪽 | 처음에는 **장비 선택 목록**(장착 중 → 초월 → 강화 순, 12칸 페이지). 고르면 닫히고 대장장이 스탠딩과 대사가 보인다. 장비 칸이나 [장비 선택]으로 다시 연다 |
| 연출 | 성공 금색 · 실패 붉은색 · 초월 보라색으로 장비 칸이 0.5초 번쩍인다 |

- 장비를 고를 때 보유한 가장 낮은 등급의 주문서가 자동으로 선택되고, +5 장비를 고르면 초월 탭으로 넘어간다
- 조건이 안 되면 버튼이 꺼지고, 강화 · 초월할 때마다 즉시 저장한다
- 씬은 다른 메뉴 씬처럼 빈 `Blacksmith.unity`에 `BlacksmithSceneRuntimePatch`가 카메라와 화면을 넣는다. 빌드 설정과 `GameScenes.Blacksmith`에도 등록했다

# Part 4. 경제 밸런스

지금까지 던전은 활력을 쓰지 않아 골드를 무한히 벌 수 있었다. 입장에 활력을 쓰게 하고 대신 보상을 올렸다.

| 던전 | 입장 활력 | 골드 (이전 → 이후) | 하루 최대 (활력 100) |
| --- | --- | --- | --- |
| DG001 무너진 성역의 숲 | 15 | 120 → 250 | 6회 · 1,500G |
| DG002 | 20 | 180 → 350 | 5회 · 1,750G |
| DG003 | 25 | 240 → 500 | 4회 · 2,000G |
| DG004 심연의 관문 | 30 | 320 → 700 | 3회 · 2,100G |

- 깊은 던전일수록 **활력당 골드 효율도 높아지게** 했다
- 입장 비용은 `DungeonData.vitalityCost`(에셋에서 조정)에 있고, 던전 상세에 「입장 활력 N (보유 M)」을 표시한다. 부족하면 입장을 막고 안내한다. 활력은 기존 Day42 규칙대로 **다음 날 전부 회복**된다
- 목표 일수(하루 최대 2,100G 기준): **+0 → +5 약 4일**(골드 7,500 + 주문서 기대 6.1장), **★1 → ★2 초월 약 9.5일**
