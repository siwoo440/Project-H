# 프로젝트 H : 70일차 개발 로그

## 오늘 목표

69일차에 메인 스토리(챕터 5)가 끝났다. 70일차는 **이야기를 다 본 뒤에도 할 것이 남도록** 세 갈래를 채웠다.

| 갈래 | 내용 |
| --- | --- |
| 💬 개인·결속 이야기 | 합류 8인에게도 개인 1화 · 결속 1~5단계 · 마을 4구역 · 여관 대사를 만들어 **12인 전원** 완성 (대사 88편) |
| ⚔️ 전용 장비 12종 | 동료마다 고유 무기. 60일차에 임시로 둔 **룬 5번 칸 조건**을 "전용 장비 ★2 초월"로 교체 |
| 🎲 야시장 놀이판 | 마을 시장에 미니게임 **5종**. 하루 3회, 골드·재료 획득 |

사용자와 정한 방식(추천안 + 야바위 추가)

1. 미니게임은 능력 축이 서로 겹치지 않게 — 기억 · 반사 · 관찰 · 판단 · 계산
2. 하루 3회는 **5종 합산**
3. 마차 균형은 골드를 걸지 않고 **재료만** 준다 (골드 인플레 차단)
4. 카드 · 다트 · 야바위는 처음부터, 내기 · 마차는 **챕터 3 완료** 후
5. 전용 장비는 개인 1화 보상으로 받고, 초월은 **결속 단계**로 한다

# Part 1. 야시장 놀이판 5종

마을 **시장** 구역에 「야시장 놀이판」 버튼이 생겼다. 배팅은 100~500G(100 단위).

| 놀이 | 능력 축 | 규칙 | 최고 배당 | 해금 |
| --- | --- | --- | --- | --- |
| **카드 뒤집기** | 기억 | 12장을 3초 보여 준 뒤 뒤집어 6쌍 찾기 (실패 8회까지) | ×2.5 | 처음부터 |
| **다트** | 반사 | 좌우로 움직이는 조준선을 과녁 한가운데에서 멈추기, 3발 | ×2.5 (150점) | 처음부터 |
| **야바위** | 관찰 | 컵 3개를 섞은 뒤 구슬이 든 컵 고르기, 3판 | ×5.0 | 처음부터 |
| **상인의 내기** | 판단 | 다음 카드가 위/아래. 멈추면 확정, **틀리면 전부 잃음** | ×4.0 (5연속) | 챕터 3 |
| **마차 균형** | 계산 | 화물 8개를 좌우에 나눠 실어 무게 맞추기 | 재료 보상 | 챕터 3 |

## 다섯 축을 나눈 이유

```text
카드 = 정적 기억   (보이지 않는 것을 외운다)
야바위 = 동적 추적 (움직이는 것을 눈으로 쫓는다)
다트 = 반사       (순간에 누른다)
내기 = 위험 관리   (멈출 때를 고른다)
마차 = 퍼즐       (시간 제한 없이 정답을 찾는다)
```

골드가 급하면 내기, 재료가 급하면 마차, 안전하게 벌려면 카드·다트 — **하루 3회 안에서 무엇을 고를지 자체가 선택**이 된다.

## 세부 수치

| 놀이 | 판정 | 비고 |
| --- | --- | --- |
| 카드 뒤집기 | 맞춘 짝 0~6 → 0 / 0.3 / 0.6 / 1.0 / 1.4 / 1.9 / 2.5배 | 부분 성공도 보상 |
| 다트 | 한 발 50·25·10점, 발마다 조준선이 빨라짐 (1.15 → 2.05) | 배당 = 점수 ÷ 60 |
| 야바위 | 1판 5회·0.34초 → 3판 12회·0.16초 | **틀려도 직전 배당의 절반** 확보 |
| 상인의 내기 | 1.3 / 1.7 / 2.3 / 3.0 / 4.0배, 같은 숫자는 성공 | 틀리면 0배 |
| 마차 균형 | 적재율 60 + 균형 40 = 100점, 한쪽 최대 5개 | 100점이면 주문서 1장 추가 |

- 마차 균형의 화물은 **같은 무게 4쌍**으로 만들어 완벽한 답이 반드시 존재한다
- 보상: 룬 조각(점수÷20) · 강화 재료(점수÷25) · 완벽 시 방어구 주문서 1
- 해금 플래그는 챕터 3 마지막 단계(`CH3_05`)에 붙였다. 68일차 이전 세이브처럼 **스토리를 이미 마친 저장도 열린다**

## 룬 5번 칸까지 가는 길

```text
개인 1화 완료 → 전용 장비 획득(★1 +0)
      ↓ 대장간에서 +5까지 강화
+5 → 결속 3단계 + 20,000G → ★2 초월 (강화는 +0으로 초기화)
      ↓ 전용 장비를 그 동료가 착용
룬 5번 칸 해금
```

- ★3은 결속 5단계 + 30,000G
- 대장간 초월 화면도 전용 장비일 때 「같은 장비 1개」 대신 「결속 N단계 (현재 M단계)」를 보여 준다
- 일반 장비로는 5번 칸이 열리지 않는다 (기획서 8.12 원래 조건)

### 테스트 기준을 두 번 고친 일

처음에 결속 대사를 "노드 3개 이상"으로 검사했다가 실패했고, "2개 이상"으로 낮췄다가 또 실패했다. 추측을 멈추고 **기존 60편의 줄 수를 전부 조사**한 결과 1줄 3편 · 2줄 13편 · 3줄 44편으로, 애초에 **줄 수로 검사하는 것이 잘못**이었다.

→ 기준을 **"그 동료가 최소 한 줄은 직접 말한다"**로 바꿨다. 길이와 무관하게 빈 껍데기 대사를 잡아내며, 120편 전부가 통과한다.

## 알아둘 점

- `GoldCurrencyService.AddGold`는 **음수를 받지 않는다**. 골드를 깎을 때는 반드시 `TrySpendGold`를 쓸 것
- 미니게임을 추가하려면 `MinigameKind`에 값을 넣고 `MinigameCatalog.Games`에 정의를, `MinigameView.StartGame`에 화면을 추가하면 된다. 배당·보상 수치는 전부 `MinigameCatalog` 한 파일에 모여 있다
- 전용 장비를 캐릭터에 붙이려면 `UniqueEquipmentCatalog`에 한 줄 추가 + 에셋 2개(`ItemData`·`EquipmentData`)를 만들어 카탈로그에 등록하면 된다
- 룬 5번 칸은 이제 **전용 장비를 그 주인이 착용 중일 때만** 열린다. 장비를 벗기면 다시 잠긴다
- 결속 대사는 편마다 줄 수가 다르다(1~3줄). 길이를 기준으로 검사하지 말 것
