# 프로젝트 H : 59일차 개발 로그

## 오늘 목표

59일차는 **결속 Runtime · 단계 및 스킬 · 궁극기 연계**를 진행했고, 사용자 요청으로 **궁극기 컷인 연출**을 함께 넣었다.

## 1. 결속 단계와 조건

캐릭터마다 **결속 1~5단계**가 있다. 기획서 호감도는 Lv.1~10이고 게임은 5단계(20씩)이므로, 조건을 게임 단계에 맞췄다. 단계는 **한 칸씩만** 올릴 수 있고, 올릴 때마다 **결속 자원 1**을 쓴다.

| 결속 | 조건 | 기획서 근거 |
| --- | --- | --- |
| 1단계 | 호감도 **안면(20)** | 결속 기본 대사 |
| 2단계 | **호감(40)** + **개인 이벤트 1화 완료** | 9.8 "이전 개인 스토리 완료 필요" — Day58 `SYS_EVENT_DONE` 플래그 활용 |
| 3단계 | **신뢰(60)** | |
| 4단계 | **유대(80)** | 9.8 "보통 Lv.7 이상" |
| 5단계 | 호감도 **100** | 15.19 "강력한 최종 보상" |

조건 판정은 Day56 `GameEventCondition`을 그대로 쓴다. 5단계의 "호감도 100"은 단계(20 단위)로 표현할 수 없어서 조건 종류 **`AffinityValueAtLeast`(호감도 수치 이상)**를 새로 추가했다. 잠긴 단계에는 "호감 이상 · 1화 「치유 연습」 완료"처럼 부족한 조건이 모두 표시된다.

## 2. 결속 자원

| 항목 | 값 (기획서 5.7) |
| --- | --- |
| 최대 | 5 |
| 회복 | 하루 지날 때 +1 |
| 새 게임 · 기존 세이브 | 첫 조회 시 1개 지급 |

`SaveData`에 `bondResource` · `lastBondRefillDay`를 추가했다. Day57 선물처럼 **조회할 때 날짜 차이만큼 채우는** 방식이라 시간 진행 코드는 건드리지 않았다.

기존 세이브는 회복 기록이 없으므로, 과거 일수만큼 한꺼번에 몰아주지 않고 **1개로 시작**한다(7일차 세이브를 열어도 7개가 아니라 1개).

자원이 부족하니 **"누구와 먼저 결속을 깊게 할까"**를 고르게 된다. 기획서 5.7이 의도한 부분이다.

## 3. 전투 효과

| 단계 | 효과 | 연결한 기존 코드 |

### 게이지 +10%의 소수점 처리

게이지는 1초에 1씩 정수로 찬다. 1 × 1.1 = 1.1을 매번 버리면 +10%가 영원히 0이 된다. 그래서 **남은 소수점을 캐릭터별로 이월**한다. 1씩 10번 충전하면 정확히 11이 된다.

### Perfect 보너스

기존 최대 배율은 1.50(전부 Perfect 풀콤보)이다. 결속 3단계는 여기에 Perfect 수만큼 더해 **최대 1.70**까지 오른다. 결속이 0이면 배율 계산은 기존과 완전히 같다.

### 4단계 패시브 강화 · 5단계 결속 스킬

기획서 15.19 "결속 보너스 방향"과 6.11의 예시를 따랐다. 4단계 수치는 계획 단계에서 적은 방향을 **실제 패시브 코드에 맞춰** 조정했다.

| 캐릭터 | 4단계 패시브 강화 | 5단계 결속 스킬 |
| --- | --- | --- |
| 세레나 | 저체력 아군 보호막 최대 체력 6% → **7.8%** (+30%) | **수호의 기도** — 아군이 체력 30% 이하가 되면 **전투당 1회** 최대 체력 20% 보호막 |
| 엘렌 | 저체력 방어력 증가 20% → **25%** | **철벽의 맹세** — 궁극기 사용 시 파티 전체 피해 감소 +10% (6초) |
| 릴리아 | 광역 스킬 방어 감소 5% → **10%** | **마력 공명** — 궁극기 뒤 남은 적마다 마력 폭발 (공격력 50% 마법 피해) |
| 이브 | 연속 적중 치명타율 +4% → **+9%** | **정령의 화살** — 치명타 시 관통 화살 1발 (공격력 40%, 3초마다) |

- 결속 스킬 피해는 궁극기와 같은 피해 함수(`BattleUltimateEffectExecutor.ApplyDamage`)를 재사용하도록 `private`에서 `internal`로 바꿨다
- 이브의 정령의 화살을 위해 기본 공격 치명타 시점에 `BattlePassiveSystem.HandleBasicAttackCritical`을 새로 호출한다

기획서 5.7의 경고("결속이 너무 강하면 장비 성장의 의미가 약해짐")에 맞춰 **강하지만 제한적으로** 잡았다. 모든 수치는 `BondCatalog` 한 파일에서 조정한다.

## 4. 파티 조합 시너지

기획서 4.8의 조합 10종 중 **지금 캐릭터로 성립하는 2종**만 넣었다. 나머지는 캐릭터가 추가되는 Day62~63에 넣는다.

| 조합 | 조건 | 효과 |
| --- | --- | --- |
| 균형 파티 | 세레나 + 엘렌 + 릴리아 + 이브 편성 | 공격력 · 방어력 · 받는 회복량 **+3%** |
| 결속의 원탁 | 결속 **3단계 이상 4명** 편성 | 궁극기 게이지 획득 **+10%** (2단계 보너스와 합산) |

결속의 원탁은 기획서의 "호감도 Lv.8 이상 4명"을 결속 단계 기준으로 바꿔 적용했다. 시너지는 Day55 탐험 효과처럼 **아군이 생성된 뒤 `BattleSkillRuntimeDriver`에서 한 번** 적용한다. 균형 파티 효과는 전투 끝까지 유지되는 Modifier라 Day51 상태이상 칩에 함께 표시된다.

## 5. 전투 정적 상태 규칙

Day56에 정리한 `BattleRuntimeStates` 규칙을 그대로 따랐다.

- 결속 단계는 **등록형**이다. 속성(Day52)처럼 `BattleStatsFactory`가 스탯을 만들 때 등록하고, **전투 시작 초기화에서는 지우지 않는다**
- 게이지 소수점 이월 · 전투당 1회 사용 기록 · 결속의 원탁은 **전투 시작 시** 초기화한다
- 전투 종료 시에는 전부 초기화한다

## 6. 결속 UI

### 캐릭터 창 [결속] 패널

Day56 호감도 보상 패널과 같은 구조다.

```text
┌ 세레나 · 결속 2/5                                   [닫기] ┐
│ 결속 자원 ◆◆◇◇◇ 2/5 · 하루 +1          [자원 +1 (테스트)] │
│ [완료]  1단계 · 결속 대사 · 최대 체력 +2%                    │
│ [완료]  2단계 · 궁극기 게이지 충전 +10%                      │
│ [올리기 · 자원 1]  3단계 · 리듬 Perfect마다 궁극기 위력 +0.04 │
│ [잠김]  4단계 · 패시브 보호막 +30%   조건 : 3단계 먼저        │
│ [잠김]  5단계 · 결속 스킬 「수호의 기도」 …                   │
│ 결속 스킬 「수호의 기도」 (5단계 해금) · …                    │
│ 조합 시너지 · 균형 파티 … / 결속의 원탁 …                    │
└────────────────────────────────────────────────────────────┘
```

- 캐릭터 창 하단 바가 7칸이 되어 간격을 다시 나눴다: `호감도 · 45/100 · 호감 · 결속 2 | -10 | +10 | 호감도 보상 | 선물하기 | 대화하기 | 결속`
- 호감도 보상 · 선물 · 결속 패널은 **동시에 열리지 않도록** `CloseOtherPanels`로 정리했다
- `자원 +1 (테스트)`는 `DevelopmentFeatures.HideInRelease`로 출시 빌드에서 숨긴다

### 결속 대사

기획서 1단계 보상이 "기본 결속 대사"다. 단계를 올리면 Day58 대화 화면으로 짧은 대사(1~3줄)가 나온다. 4인 × 5단계 **20편**이고, 기획서 캐릭터별 이벤트 방향을 한 단계씩 따라가도록 썼다.

| 캐릭터 | 흐름 | 5단계 마지막 대사 |
| --- | --- | --- |
| 세레나 | 역할 → 한 사람 | "…그러니 용사님도, 제 곁에서 너무 무리하지 마세요." |
| 엘렌 | 명령 → 자기 의지 | "제 의지로 맹세합니다. 당신이 서 있는 곳이, 제가 지킬 전선입니다." |
| 릴리아 | 논리 → 신뢰 | "아직 모르겠어. 그래도 믿어 볼게." (기획서 28번 성장 후 말버릇) |
| 이브 | 불신 → 믿음 | "당신은… 나의 빛." (기획서 Lv.10 대사) |

### 전투 HUD 결속 배지

초상화 **우상단**에 `◆3`처럼 결속 단계를 표시한다. Day54 숫자키 배지(좌상단)와 같은 모양을 재사용하고 보라 바탕 · 금색 글자로 구분했다. 결속 0이면 숨긴다.

## 7. 궁극기 컷인 (사용자 요청)

궁극기를 쓰면 **캐릭터 일러스트와 궁극기 이름**이 나오는 컷인을 넣었다. 기획서 12.18도 "궁극기 발동 — 캐릭터 얼굴 또는 전신 컷인"으로 정해 두었다.

```text
궁극기 → 게이지 소비 → 전투 일시정지 → [컷인 1.5초] → 리듬 챌린지 → 효과
```

```text
┌──────────────────────────────────────────────┐
│ ░░░░░░░░░░ (전투 화면 어둡게) ░░░░░░░░░░░░░░ │
│   ╱▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔╱   │
│  ╱ [세레나     ]      성 광 의 심 판      ╱    │
│ ╱  [일러스트 ◀]      세레나 · ULTIMATE   ╱     │
│╱▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁╱      │
│        “리리아스여, 모두에게 빛을!”             │
└──────────────────────────────────────────────┘
```

| 구간 | 시간 | 연출 |
| --- | --- | --- |
| 등장 | 0 ~ 0.25초 | 배경이 어두워지고 캐릭터 색 사선 띠가 펼쳐지며, 일러스트가 왼쪽에서 감속하며 들어옴 |
| 유지 | 0.25 ~ 1.15초 | 궁극기 이름이 1.35배로 튀어나왔다 제자리로. 일러스트는 천천히 밀림 |
| 퇴장 | 1.15 ~ 1.5초 | 띠가 접히고 일러스트가 오른쪽으로 빠지며 사라짐 |

- `BattleHudCardView.TryUseUltimate`에서 리듬 챌린지를 여는 한 줄을 **"컷인 → 끝나면 챌린지"**로 바꿨다. 전투가 이미 멈춘 상태라 컷인은 `unscaledDeltaTime`으로 움직인다
- 일러스트는 띠에 `Mask`를 걸어 **가슴 위만** 보이게 잘랐다. 띠가 7° 기울어져 있어도 스텐실 마스크라 정확히 잘린다
- 컷인 도중 **클릭하면 바로 챌린지로** 넘어간다(기획서 12.18 "컷인 스킵"). `UltimateCutInView.Enabled` 스위치를 만들어 두었고, Day71 설정 일차에 켜기/끄기와 연결한다
- 시간 계산은 `UltimateCutInTimeline`으로 화면과 분리해 테스트했다
