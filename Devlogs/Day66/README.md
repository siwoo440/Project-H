# 프로젝트 H : 66일차 개발 로그

## 오늘 목표

66일차는 모험 지도의 **북쪽(카르니안 제국)과 남쪽(아스타르 사막)**을 열고, 추가 요청으로 **던전이 있는 모든 지역을 던전 2개씩** 갖추게 했다. 던전은 6개에서 **14개**가 되었고, 지도에서 잠긴 곳은 바다(67일차)만 남았다.

사용자와 정한 방식(추천안 + 추가 요청)

1. 카르니안 · 아스타르는 **마왕성 클리어 후 후반 지역** (권장 Lv.9 · 10)
2. 지역 특징은 65일차(적 강화 · 적 회복)와 겹치지 않게 **우리 편이 불리해지는 방식**(혹한 · 모래폭풍)
3. 사막 첫 방문 안내는 **세레나**(봉인 · 여신 복선, 항상 보유한 초기 동료)
4. 카르니안 첫 방문 안내는 **엘렌 혼자** (파이라는 합류 전일 수 있어 70일차 개인 스토리에서)
5. (추가) **지역마다 던전 2개**를 난이도 계단에 맞게 배치
6. (추가) 다음에 갈 던전을 찾기 쉽게 **새 던전 안내 아이콘**을 지역 위 · 던전 칸 앞에 표시 — 글자가 아닌 **그림**

## 밸런스 기준

| 항목 | 기준 | 범위 |
| --- | --- | --- |
| 골드 | 약 150 + 70 × 레벨 (같은 레벨은 서로 조금씩 다르게) | 550 ~ 1,060 |
| 경험치 | 기존 공식 60 + 20 × 레벨 | 180 ~ 320 |
| 활력 | 레벨이 오를수록 증가 | 25 ~ 35 |
| 적 배율 (체력 기준) | 레벨이 오를수록 증가, 던전마다 모두 다름 | 2.55배 ~ 5.5배 |
| 드롭 | 레벨 단계마다 B급 주문서 · 룬 상자 2 확률 +2%p, 재료 · 룬 조각 수량 증가 | — |
| 층 수 | 첫 번째 던전 5층 · 두 번째 던전 6층 | — |

- 해금은 **항상 더 쉬운 던전 뒤**에 열린다(테스트로 보장). 가장 어려운 검은 성벽은 사막 지하 고대 도시를 깨야 열린다
- 두 번째 던전은 그 지역 몬스터를 웨이브당 3~4마리로 늘리고 새 보스를 둔다. 검은 성벽은 "마왕군이 각지 괴물을 모았다"는 설정으로 모든 지역 몬스터를 섞었다
- 잠긴 던전 칸 안내가 ID 대신 **"지역 · 던전 이름 클리어 필요"**로 나온다(예: 사막 · 지하 고대 도시 클리어 필요)
- 마을 길드 게시판은 던전이 늘어 글이 넘치지 않도록 **열린 던전만** 보여 준다

# Part 2. 몬스터 14종 · 보스 패턴 8종

| 지역 | 일반 몬스터 | 보스 (첫 번째 / 두 번째 던전) |
| --- | --- | --- |

| 사막 | 모래 전갈(불 · 돌격) · 태양 신전 미라(빛 · 전선) · 고대 골렘 파편(불 · 원거리) | **고대 봉인 수호체**(빛) / **고대 도시의 망령왕**(어둠) |
| 늪지대 | (기존 몬스터) | — / **독안개 히드라**(풀) |
| 노아르 | (65일차 몬스터) | 폭주한 마도 골렘 / **실험체 키메라**(어둠) |
| 실바란 | (65일차 몬스터) | 타락한 정령왕 / **세계수 뿌리의 파수룡**(빛) |

- 새 보스는 체력 50% 또는 150초에 폭주하는 2페이즈다. 검은 기사단장만 기존 최종 보스처럼 60% · 25%(180초)로 바뀌는 3페이즈다
- 패턴은 보스마다 4개(검은 기사단장 5개)이며, 네 가지 종류(전체 공격 · 단일 강타와 기절 · 자기 방어 강화 · 흐트러짐 회복)를 조합했다. 2페이즈의 마지막 대기술은 흐트러짐으로 취소되지 않는다
- 모든 몬스터에 일기장 설명을 넣었고, 데이터 목록(`ProjectHDataCatalog`)에 등록했다(몬스터 26종 · 던전 14개)

# Part 3. 지역 특징 — 우리 편이 불리해지는 방식

| 특징 | 발동 | 효과 | 공략 |
| --- | --- | --- | --- |
| 카르니안 **혹한** | 8초마다 | 살아 있는 아군마다 공격 속도 −10% 1중첩 추가 (최대 3중첩 −30%, 20초 유지) | **정화하면 0부터 다시** 쌓인다 — 세레나 · 클레어 |
| 사막 **모래폭풍** | 12초마다 | 6초간 아군 명중률 −25% | 정화 가능, 폭풍이 없는 틈에 공격 |

- 둘 다 정화할 수 있는 약화로 등록된다
- 혹한 중첩은 캐릭터마다 따로 센다. 이를 위해 특정 출처의 현재 수치를 읽는 `BattleSkillRuntimeState.GetModifierValue`를 추가했다
- 같은 지역의 두 번째 던전은 같은 특징을 가진다(노아르 2 = 마나 폭주, 실바란 2 = 정령의 가호). 늪지대 · 마왕성은 특징이 없다

# Part 4. 첫 방문 이야기 · 지도

| 대사 | 동료 | 내용 |
| --- | --- | --- |
| `REGION_KARNIAN_ARRIVAL` 「돌아온 설원」 | 엘렌 | 처음 검을 받은 요새, 마을을 버리라는 명령을 따랐던 과거, 침식된 옛 동료들. "이번엔 명령이 아니라 제 뜻으로 검을 들겠습니다" |
| `REGION_DESERT_ARRIVAL` 「모래 아래의 봉인」 | 세레나 | 신탁에서 본 신전과 봉인 장치, 여신이 보여 주지 않은 것. 누군가 지운 문양 — 69일차 "봉인의 진실" 복선 |

- 두 번째 던전으로 먼저 들어가도 그 지역 첫 방문 이야기가 나오고, 한 번 본 지역에서는 다시 나오지 않는다
- 세계관 단어 "카르니안 제국" · "아스타르 사막"은 첫 방문 때 열린다. 일기장 "지역" 분류는 4편이 되었다
- 지도에 **북쪽 카르니안 설원**(눈 덮인 땅)을 새로 그렸고, 사막 지역은 잠김에서 던전 지역으로 바뀌었다
- 대화 배경 `KARNIAN`(눈보라 요새) · `DESERT`(달궈진 모래 언덕) 임시 색을 추가했다

# Part 5. 새 던전 안내 아이콘 (추가 요청)

```text
      (!)                         ┌──────────────────────────────┐
     ( 늪 )   ← 지역 원 위         │ (!)  독안개 저습지             │ ← 던전 칸 앞부분
     늪지대                        │      권장 Lv.6  활력 25  560G │
                                  │      진입 가능                │
                                  └──────────────────────────────┘
```

- 안내 대상은 **열렸지만 아직 클리어하지 않은 던전**이다. 클리어하면 사라지고, 새로 열린 던전으로 옮겨 간다
- 지역 원 위 아이콘은 위아래로 살짝 흔들려 눈에 띈다. 던전 칸은 아이콘 자리만큼 글자를 오른쪽으로 민다. 아이콘은 클릭을 막지 않는다
- 예: 새 게임 → 숲 · DG001 / DG001 클리어 → DG002 / 늪지대까지 클리어 → 마왕성 · 노아르 · 실바란 · 늪지대 두 번째 던전 네 곳
- 이미 진행한 세이브도 불러오는 순간 새로 추가된 던전(DG009 등)에 바로 표시된다
- 아이콘은 **글자가 아니라 코드로 그린 그림**(노란 원 · 갈색 테두리 · 느낌표 모양, `DungeonAlertArt`)이다. `Resources/UI/Icons/ALERT.png`를 넣으면 정식 아이콘으로 바뀐다
- 판정은 `DungeonGuideService`(새 던전 여부 · 지역에 새 던전이 있는지 · 목록)가 맡는다
