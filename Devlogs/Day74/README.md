# Part 1. 성능 점검

## 매 프레임 낭비 조사

`Update()`를 가진 클래스 **18개**의 본문을 전부 열어, 매 프레임 무거운 일(오브젝트 탐색 · 리소스 로드 · 목록 생성 · 문자열 조립)을 하는지 기계적으로 훑었다.

| 결과 | 내용 |
| --- | --- |
| 탐색·로드·목록 생성 | **0건** |
| 문자열 조립 | 1건 — 보스 패턴 예고 로그. `if` 안에서만 실행되어 매 프레임이 아님 |

→ 60일차 최적화 정리 이후로 유지되고 있었다. **고칠 것이 없었다.**

## 출시 빌드 로그 제거 (실제로 고친 것)

로그를 세어 보니 **140건**이었다.

| 종류 | 수 | 처리 |
| --- | --- | --- |
| `Debug.Log` (진행 안내) | 69 | **출시 빌드에서 통째로 제거** |
| `Debug.LogWarning` | 17 | 유지 (원인 추적에 필요) |
| `Debug.LogError` | 54 | 유지 |

`GameLog.Info`를 만들고 `[Conditional("UNITY_EDITOR")]` · `[Conditional("DEVELOPMENT_BUILD")]`를 붙였다. 이 속성은 **호출 자체를 컴파일에서 지우므로**, 인자로 넘기던 `$"..."` 문자열 조립도 함께 사라진다.

런타임 코드 **20개 파일 · 48건**을 자동 변환했다(에디터 코드는 빌드에 들어가지 않으므로 제외).

> 변환 중 한 곳이 `UnityEngine.Debug.Log(...)`로 풀 네임을 쓰고 있어 `UnityEngine.GameLog`가 되어 버렸다. 빌드가 바로 잡아 주어 수정했다.

# Part 2. 출시 점검 테스트 — `ReleaseCandidateTests`

사람이 손으로 끝까지 플레이하지 않아도 **막히는 곳을 찾아내는** 테스트 5개를 만들었다.

| 테스트 | 검증 |
| --- | --- |
| 전체 진행 | 새 게임부터 최종장까지 한 번도 맴돌지 않고 도달 · **12인 전원 합류** · 메인 대사 32편 · 챕터 던전 단계 8개 이상 |
| 엔딩 연결 | 네 조합이 각각 다른 엔딩으로 이어지고, 회차 기록이 4회 쌓이며, **같은 저장에서 두 번 재생되지 않음** |
| 던전 체인 | 17던전이 하나도 끊기지 않고 순서대로 열림 (열 수 있는 던전이 없으면 **남은 던전 이름과 함께 실패**) |
| 깨진 저장 복구 | 음수 일차 · 음수 활력 · `null` 목록투성이 JSON을 넣어도 예외 없이 기본값으로 복구되고, 스토리·놀이판 진입이 가능 |
| 새 게임 상태 | 1일차 · 세레나 1인 · DG001 열림 · 이름 입력 대기 · 놀이판 3회 |

특히 **던전 체인 테스트**는 "열 수 있는 던전이 하나도 없다"는 상황을 직접 잡아내므로, 앞으로 던전을 추가하다 해금 사슬을 끊으면 즉시 실패한다.

# Part 3. 캐릭터 스탠딩 12종

대화 화면의 인물이 아직 **색 실루엣**이었다. 73일차 초상화와 같은 규칙(캐릭터 고유색 · 앞머리 3종)으로 **전신 그림**을 만들었다.

| 항목 | 내용 |
| --- | --- |
| 규격 | 512×1024 · **투명 배경 RGBA PNG** |
| 구성 | 머리(뒷머리·앞머리·하이라이트) · 얼굴(눈·홍조·입) · 몸통 · 팔 · 손 · 치마 · 다리 · 신발 |
| 경로 | `Resources/Dialogues/Standing/{캐릭터ID}.png` — 63일차 로더가 자동으로 실루엣을 대체 |

### 두 군데를 고쳤다

- **머리 윗부분이 각졌다** — 앞머리를 고정 폭으로 칠해 두상 타원 밖까지 나갔기 때문. 행마다 두상 타원의 반폭으로 제한해 둥글게 남겼다
- **팔이 몸통에 묻혔다** — 옷과 같은 색이라 실루엣이 하나로 보였다. 팔만 10% 어둡게
- `.meta`의 `alphaIsTransparency`를 **1**로 (투명 가장자리에 검은 테두리가 생기는 것을 막는다)

## 알아둘 점

- 안내 로그는 **`GameLog.Info`**를 쓸 것. `Debug.Log`를 직접 쓰면 출시 빌드에 남는다
- 경고·오류(`GameLog.Warn` · `GameLog.Error`)는 **일부러 출시 빌드에도 남긴다**
- 던전·챕터를 늘린 뒤에는 `ReleaseCandidateTests`를 꼭 돌릴 것. 진행이 막히면 **어디서 막혔는지 이름까지** 알려 준다
- 투명 PNG의 `.meta`는 `alphaIsTransparency: 1`
