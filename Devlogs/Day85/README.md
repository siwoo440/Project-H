# Part 1. 캐릭터 화면 본체

캐릭터 화면은 글자가 전부 어두운색이다. 그래서 **밝은 계열**로 입혔다.

| 부분 | 전 | 후 |
| --- | --- | --- |
| 뒤로 · 도움말 · 설정 | 하늘색 상자 + 글자 기호 | 밝은 청회색 버튼 + 아이콘 |
| 골드 표시 | 회색 상자 + 노란 원에 `G` | 안쪽 칸 + 금화 아이콘 |
| 이전 · 다음 캐릭터 | `◀ ▶` | 화살표 아이콘 |
| 일러스트 칸 | 흰 상자 + 외곽선 | 카드 |
| 탭 5개 | 고른 탭만 하늘색 | 고른 탭은 밝은 금색, 나머지는 어두운 청회색 **그림 교체** |
| 내용 틀 | 이중 외곽선 상자 | 밝은 창 + 안쪽 칸 |
| 스텟 탭 기능 버튼 | 옅은 색 상자 | 카드 + 같은 옅은 색 |
| 장비 5칸 | 등급 색 상자 | 은테 칸 + 밝게 섞은 등급 색 |
| 보유 장비 목록 | 회색 줄, 고른 줄은 하늘색 | 카드, 고른 줄은 금빛 |
| 장착 버튼 | 연두 상자 | 주황 |

## 장비 칸의 외곽선은 남겼다

다른 곳에서는 스킨을 입히면 코드 외곽선을 끈다. 장비 5칸은 예외다. 이 칸의 외곽선은 테두리 장식이 아니라 **"지금 이 부위를 보고 있다"는 표시**(금색)로 쓰인다. 그래서 그림만 바꾸고 외곽선은 그대로 두었다.

## 옅은 상태 색은 건드리지 않았다

84일차에는 진한 상자 색이 그림을 죽여서 따로 다뤄야 했다. 이 창들의 상태 색은 사정이 다르다.

| 창 | 상태 색 |
| --- | --- |
| 선물하기 | 분홍(아주 좋아함) · 연두(좋아함) · 베이지(보통) · 회청(별로) · 회색(모름) |
| 결속 | 금색(올릴 수 있음) · 연보라(완료) · 회색(잠김) |
| 호감도 보상 | 금색(받기) · 연두(받음) · 회색(잠김) |

모두 **밝고 옅은 색**이다. 아이보리 카드 위에 곱해도 색감이 그대로 남는다. 그래서 색을 바꾸는 코드는 그대로 두고 바탕만 카드 그림으로 바꿨다.

## 룬 칸

룬 아이콘의 어두운 칸을 아이템 칸과 같은 은테 칸으로 맞췄다. 잠긴 칸은 예전에 진한 회색을 넣었는데, 그림 위에서는 옅은 어두운 기로 바꿔 넣는다.

## 알아둘 점

- **옅은 상태 색은 카드 위에 그대로 입혀도 된다.** 진한 색만 `SetState` · `Hint`로 바꿔 넣는다
- **외곽선이 "고른 것" 표시로 쓰이는 곳은 `UiSkinKit.Panel` 대신 `UiSkin.Apply`를 쓸 것.** `Panel`은 외곽선을 끈다
- 색이 게임 정보인 곳(미니게임 말 · 노드 종류)에는 스킨을 입히지 않는다
