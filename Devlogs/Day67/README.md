# 프로젝트 H : 67일차 개발 로그

## 오늘 목표

67일차는 **매일 들어올 이유**(검은 균열 · 길드 의뢰)를 만들고, **14 → 16던전의 난이도를 처음으로 제대로 맞췄다**. 추가 요청으로 마을 · 모험 지도의 오른쪽 패널을 스크롤할 수 있게 고쳤다.

| 기능 | 한 줄 설명 |
| --- | --- |
| 🌀 검은 균열 · 긴급 던전 | 3일마다 한 지역에 균열이 열리고, 3일 안에 막으면 보상 1.5배 + 침식도 감소, 놓치면 침식도 증가 |
| 🌊 바다 지역 개방 | 마지막 잠김 지역이 열려 던전 16개 완성 (검은 균열 해안 Lv13 · 균열 심층 Lv15) |
| 📜 길드 의뢰 | 마을 길드에 하루 3개, 전투 결과로 자동 진행, 완료 시 보상 · 전부 완료 보너스 |
| ⚖️ 1차 밸런스 | 계산기를 만들어 16던전 전투 시간을 목표 범위로 맞춤 (전투가 망가져 있던 것을 발견해 수정) |
| 🖱️ 패널 스크롤 (추가 요청) | 마을 모든 구역 · 모험 지도 오른쪽 패널이 넘치면 휠로 내려서 보기 |

사용자와 정한 방식(추천안)

1. 균열은 **3일마다 1곳, 3일 유지**
2. 놓치면 **침식도 +10** (작은 불이익)
3. 바다에도 **던전 2개** (지역마다 2개 규칙 유지)
4. 길드 의뢰는 **하루 3개**
5. 밸런스는 **캐릭터 성장 ↑ + 적 배율 정리**를 함께

# Part 2. 검은 균열 (긴급 던전)

```text
[모험 지도]                          [지역 패널]
      (🌀)                           ┌───────────────────────────────┐
     ( 늪 )  ← 소용돌이 표시          │ 긴급 · 검은 균열 (남은 2일)      │
     늪지대                           │ 독안개 저습지 깊은 곳에서 …      │
                                     │ [ 검은 균열 막기 (활력 25) ]     │
                                     └───────────────────────────────┘
```

| 항목 | 내용 |
| --- | --- |
| 해금 | 마왕성(심연의 관문) 클리어 후 |
| 주기 | **3일마다** 한 지역, **3일간** 유지 (같은 날이면 항상 같은 지역, 세이브에 기록) |
| 장소 | 그 지역에서 **열려 있는 가장 어려운 던전** (잠긴 곳에는 열리지 않음) |
| 성공 | 골드 **1.5배** + 그 지역 침식도 **−20** |
| 실패(기한 초과) | 침식도 **+10**, 균열은 사라지고 다음 주기를 기다림 |
| 표시 | 지역 원 위 **보라색 소용돌이 그림**(글자 아님) · 지역 패널 맨 위 긴급 칸 · 지도를 열면 안내 문구 |

- `RiftService`가 화면을 열 때마다 기한 만료와 새 균열을 처리한다(모험 지도 · 마을 양쪽에서 호출)
- 균열 탐험 여부는 `RiftRunState`로 씬을 넘어 유지되고, 보스를 잡아 던전을 클리어했을 때만 봉쇄로 인정된다

# Part 4. 1차 밸런스

## 발견한 문제

계산기를 만들어 재 보니 전투가 **양쪽 다 망가져** 있었다.

| 문제 | 수치 |
| --- | --- |
| 전투가 너무 빨리 끝남 | 보스전 최대 59초, 일반 웨이브 1~21초 |
| 적이 아군을 거의 못 때림 | 적 공격력 10~42 vs 아군 방어력 160~300 → **한 대에 1 피해**, 전멸까지 6,000~26,000초 |

원인은 **몬스터 수치와 캐릭터 수치가 서로 다른 시기에 만들어진 것**이었다(몬스터 공격 10 vs 캐릭터 공격 180).

## 조정

| 항목 | 이전 | 이후 |
| --- | --- | --- |
| 캐릭터 레벨당 성장 | +5% | **+8%** |
| 몬스터 공격력 | 8 ~ 42 | **185 ~ 305** |
| 몬스터 체력 | 2,100 ~ 24,000 | **12,900 ~ 150,800** |
| 던전 배율(체력) | 1.00 ~ 6.20 (들쭉날쭉) | **1.00 ~ 3.24** (레벨 기준 공식 + 같은 레벨 구분용 미세 차이) |

수치는 목표에서 역산했다.

- 일반 몬스터 한 대 = 아군 최대 체력의 **1.2%**, 보스 한 대 = **3.5%**
- 일반 웨이브(3마리) 처치 **30초**, 보스 처치 **70초 + 레벨당 4.5초**(최대 135초)

## 결과 (권장 레벨 · 장비 평균 기준)

| 구간 | 일반 웨이브 | 보스 | 전멸까지 여유 |
| --- | --- | --- | --- |
| 초반 (Lv1~5) | 10 ~ 23초 | — (보스 몬스터 없음) | 매우 넉넉 |
| 중반 (Lv6~10) | 23 ~ 43초 | 92 ~ 110초 | 보스 1.5 ~ 1.8배 |
| 후반 (Lv11~15) | 30 ~ 45초 | 115 ~ 133초 | 보스 1.2 ~ 1.8배 |

- 회복 담당 없이 보스를 잡기 어렵고, 오래 끌면 지는 구도가 되었다
- `BalanceSimulator`(순수 계산)가 던전별 예상 처치 시간 · 버티는 시간 · 여유 비율을 계산한다
- 에디터 메뉴 **Tools → Project H → Phase 2 → 67일차 밸런스 표 출력**로 16던전 표를 콘솔에서 볼 수 있다

# Part 5. 패널 스크롤 (추가 요청)

의뢰가 늘어나면서 길드 패널의 버튼이 화면 밖으로 밀리는 문제가 있었다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 마을 **모든 구역**(길드 · 광장 · 시장 · 온천 · 여관) + 모험 지도 지역 패널 |
| 구조 | 패널 → 보이는 영역(`RectMask2D`) → 내용, 패널에 `ScrollRect`(세로 전용) |
| 배치 | 줄을 **위에서부터 픽셀로 쌓는 방식**(`PlaceRow`)으로 교체. 호출부는 기존 비율 값을 그대로 쓰고 내부에서 환산한다 |
| 높이 | 줄을 다 그린 뒤 실제 높이를 넣는다. 짧으면 스크롤되지 않는다 |
| 스크롤 위치 | 같은 구역·지역을 다시 그릴 때는 보던 위치 유지, 다른 곳으로 옮기면 맨 위부터 |
| 조작 | 휠 · 드래그, 관성 없음(`inertia = false`), 끝에서 멈춤(`Clamped`), 감도 40 |

## 알아둘 점

- 밸런스 기준값(장비 1.35배 · 스킬 몫 1.6배 · 회복 몫 1.3배 · 목표 시간)은 `BalanceSimulator` 상수 한 곳에 있다. 수치를 바꾸면 테스트가 바로 알려 준다
- 몬스터 수치를 손으로 고치면 목표에서 벗어나기 쉽다. 규칙(일반 1.2% · 보스 3.5% · 처치 시간)을 먼저 정하고 역산하는 방식을 유지할 것
- 균열은 마왕성 클리어 전에는 나타나지 않는다. 테스트에서 균열을 보려면 DG004를 클리어한 세이브가 필요하다
- 패널 스크롤은 기준 높이(`PanelViewHeight`)로 비율을 픽셀로 환산한다. 줄 간격이 어색하면 이 값만 조정하면 된다
