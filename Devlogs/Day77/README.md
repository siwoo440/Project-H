## 오늘 목표

76일차에 캐릭터 그림 84장을 넣었다. 그런데 **화면의 틀은 예전 그림에 맞춰져 있었다.**

예전에 코드로 그린 그림은 머리가 아주 큰 2등신에 가까웠고, 새 그림은 8등신 전신이다. 같은 자리에 넣으면 얼굴이 훨씬 작게 나온다. 대화 화면에서는 얼굴(눈썹~턱)이 화면 높이의 약 7%였다. 표정 7종을 만들어 놓고 잘 보이지 않는 셈이다.

오늘은 **새 그림에 맞춰 화면의 틀을 다시 잡았다.**

# Part 2. 대화 화면 구도 — `DialogueStandingFrame`

## 바꾼 것

| 항목 | 전 | 후 |
| --- | --- | --- |
| 크기 | 전신이 화면 높이에 맞음 | **1.4배** |
| 머리 위치 | 화면 위에서 5% | 그대로 |
| 아래쪽 | 발이 대사창 바로 뒤 | 허벅지 아래가 대사창 뒤로 내려감 |
| 기준점 | 영역 가운데 | **위쪽 가운데** |

- 위쪽을 고정하고 아래로만 키웠다. 그래서 배율을 바꿔도 머리 위치가 흔들리지 않는다
- 기준점을 위쪽으로 옮긴 이유 — 듣는 쪽 캐릭터를 4% 줄이는 연출이 있는데, 가운데 기준이면 줄어들 때 머리가 아래로 내려간다
- 배율은 `DialogueStandingFrame.Scale` **숫자 하나**다. 1 = 전신 · 1.4 = 허벅지까지 · 1.7 = 허리까지

## 영역을 넓게 잡은 이유

Unity의 `Image`는 비율을 지키며 그릴 때, 영역이 좁으면 **가로에 맞춰 줄여 버린다.** 배율을 올렸는데 캐릭터가 커지지 않는 일이 생긴다.

그래서 영역 가로를 화면의 80%로 넉넉하게 잡았다. 그림의 투명한 여백은 보이지 않고 클릭도 받지 않으므로 겹쳐도 문제가 없다. 배율 2.2까지는 높이에 맞춰 그려진다.

# Part 3. 초상화 — 스탠딩에서 잘라 쓰기

마을 지도 카드의 얼굴은 73일차에 코드로 그린 초상화였다. 새 스탠딩과 그림체가 다르다.

초상화를 12장 더 받는 대신, **스탠딩 그림의 얼굴 주변을 잘라** 쓰기로 했다.

| 항목 | 내용 |
| --- | --- |
| 자르는 영역 | 얼굴 중심을 가운데 둔 정사각. 한 변 = 얼굴 높이 × 2.6 |
| 들어오는 범위 | 머리 전체와 어깨선 |
| 방식 | 같은 텍스처의 **일부 영역만 가리키는 스프라이트**. 그림 파일을 새로 만들지 않는다 |
| 찾는 순서 | 전용 그림(`Resources/Portraits/{ID}`) → 스탠딩에서 자른 얼굴 → 색 원 |

- 메모리를 더 쓰지 않는다. 스탠딩 텍스처를 그대로 쓰기 때문이다
- 그림체가 저절로 맞는다. 스탠딩을 바꾸면 초상화도 함께 바뀐다
- 나중에 전용 초상화를 넣으면 그쪽이 우선이다

## 마을 카드

잘라 낸 얼굴은 **배경이 투명**하다. 예전 초상화는 불투명한 정사각이라 흰 테두리가 칸 모양으로 그려졌는데, 투명한 그림에 테두리를 그리면 머리 윤곽을 따라 그려진다.

→ 캐릭터 색을 가라앉힌 **바탕 칸**을 깔고, 테두리는 바탕 칸에 그렸다.

## 대장간 장착자 칸

전신 그림을 크게 놓고 위쪽만 보여 주던 방식이었다. 새 그림 비율로는 얼굴이 작게 나와서, 같은 얼굴 초상화로 바꾸고 틀을 가득 채우게 했다.

# Part 4. 궁극기 컷인

띠(높이 250) 안에 가슴 위만 보이는 연출이다. 380×760 칸에 전신 그림을 넣고 있었는데, 새 그림은 얼굴이 작고 허리까지 보였다.

| 항목 | 내용 |
| --- | --- |
| 크기 | 얼굴이 띠 안에서 높이 110으로 보이게 그림 전체를 키움 |
| 위치 | **얼굴 중심을 기준점(피벗)으로** 삼아 띠 가운데 근처에 놓음 |
| 가로 | 정지 위치를 -430 → -520 (그림이 커져 궁극기 이름과 겹치지 않게) |
| 적용 조건 | 정식 스탠딩을 쓸 때만. 전용 컷인 그림이 있거나 실루엣이면 예전 방식 |

얼굴 중심을 기준점으로 삼으면 계산이 간단해진다. "얼굴을 여기에 놓아라"가 곧 위치 값이 된다.

## 알게 된 것

그림을 채팅에 붙여 넣으면 **WebP로 변환된 사본**이 온다. Unity는 WebP를 읽지 못한다. 같은 출력 폴더에서 원본 PNG를 찾아 넣었다.

## 상점 · 대장간 화면

NPC 자리도 예전 실루엣 기준이라 전신이 작게 들어갔다. 대화 화면과 **같은 배율**로 키웠다. `DialogueStandingFrame.Scale` 하나가 대화 · 상점 · 대장간에 함께 적용된다.

## 알아둘 점

- **스탠딩을 새로 받으면 `StandingFaceCatalog`의 값을 다시 잴 것.** 초상화와 컷인이 이 표로 얼굴을 찾는다. 값이 어긋나면 얼굴이 잘린다
- 캐릭터 크기를 바꾸는 숫자는 세 곳이다

| 바꾸고 싶은 것 | 고칠 곳 | 지금 값 |
| --- | --- | --- |
| 대화 · 상점 · 대장간의 캐릭터 크기 | `DialogueStandingFrame.Scale` | 1.4 |
| 초상화에 머리가 들어오는 범위 | `StandingFaceCatalog.PortraitScale` | 2.6 |
| 궁극기 컷인의 얼굴 크기 | `UltimateCutInView.FaceHeightInBand` | 110 |

- 캐릭터 창 · 일기장 · 마을 구역 화면은 전신이 어울리는 자리라 그대로 두었다
- 로웰과 브론은 게임에 성별과 외모가 정해져 있지 않았다. 말투를 보고 로웰은 여성 상인, 브론은 중년 남성으로 요청했다
- 채팅에 붙여 넣은 그림은 쓰지 말고 원본 PNG를 쓸 것
