## 1. 대화 화면 — 미연시 구성

사용자 요청으로 일반적인 미연시(비주얼 노벨) 화면 구성을 따랐다.

```text
┌「치유 연습」 성역 · 조용한 연습 자리 ─────────────────┐
│                  [배경]                               │
│                  ┌──────────┐                        │
│                  │ 스탠딩    │                        │
│  ┌────────┐      │          │                        │
│  │ 세레나  │      │          │                        │
│ ┌┴────────┴───────────────────────────────────────┐ │
│ │ 서두르지 않아도 괜찮아요. 저도 곁에서 기다릴게요. ▼ │ │
│ └─────────────────────────────────────────────────┘ │
│                          SKIP   AUTO   LOG   CLOSE  │
└─────────────────────────────────────────────────────┘
```

| 요소 | 구성 |
| --- | --- |
| 배경 | 화면 전체. 장소마다 다른 색 |
| 스탠딩 | 화면 중앙. 하체는 대화창 뒤로 가려짐. 주인공이 말할 때는 살짝 어두워짐 |
| 이름표 | 대화창 왼쪽 위의 진보라 탭. 나레이션일 때는 숨김 |
| 대화창 | 하단 반투명 보라색. 대사는 **타자 효과**로 한 글자씩 표시, 끝나면 ▼ 깜빡임 |
| 장소 표시 | 좌상단에 「제목」 · 장소 |
| 선택지 | 화면 가운데 세로 버튼 |

### 하단 메뉴 — SKIP · AUTO · LOG · CLOSE만

참고 이미지의 메뉴(SAVE · LOAD · SKIP · JUMP · AUTO · LOG · CLOSE · SCREEN · TITLE · QUIT) 중 **사용자 요청대로 네 개만** 구현했다.

| 버튼 | 동작 |
| --- | --- |
| **SKIP** | 기획서 탭 2의 문구대로 "해당 장면을 건너뛰시겠습니까?" 확인 창 → **다음 선택지까지, 선택지가 없으면 끝까지** 이동. 선택지는 건너뛸 수 없다 |
| **AUTO** | 대사를 다 읽을 시간(1초 + 글자당 0.035초)이 지나면 자동으로 넘김. 켜지면 `AUTO ●` 금색 |
| **LOG** | 지나간 대사와 고른 선택지를 스크롤 목록으로 보여줌. 이름은 연보라, 선택지는 금색 |
| **CLOSE** | 대화창과 메뉴를 숨겨 배경과 스탠딩만 보여줌. 아무 곳이나 클릭하면 복귀 |

CLOSE는 미연시 관례와 기획서 탭 2의 "UI 비활성화"를 따라 **창을 닫는 버튼**이지 대화를 끝내는 버튼이 아니다. 대화를 도중에 빠져나가는 버튼은 넣지 않았다. 빠르게 끝내려면 SKIP을 쓰면 된다.

조작: 클릭 · **Space · Enter**로 넘기기. 타자 효과 도중에 누르면 대사 전체가 한 번에 나온다. ESC는 LOG 창과 확인 창을 닫는다.

### 임시 아트와 정식 아트 교체 경로

아직 정식 일러스트가 없어서 코드로 임시 이미지를 만들었다(`DialogueArtFactory`). Day49 리듬 원형 스프라이트와 같은 방식이다.

- **배경**: 하늘 그라데이션 + 지평선 + 바닥 + 좌우 음영. 밤 장면(관측실 · 밤 일상)에는 별이 뜬다. 성역 연습 자리 · 아침 회랑 · 밤의 관측실 · 정원 연못 · 아침/낮/저녁/밤 8종
- **스탠딩**: 머리 · 긴 머리 · 몸통 실루엣에 캐릭터 색을 입히고, 이름과 현재 표정 글자를 올렸다. 세레나 아이보리 · 엘렌 강철 남색 · 릴리아 청보라 · 이브 숲 초록

정식 아트가 생기면 **코드 수정 없이** 파일만 넣으면 된다.

| 종류 | 경로 (Sprite로 임포트) |
| --- | --- |
| 배경 | `Resources/Dialogues/Backgrounds/{배경키}` |
| 스탠딩 | `Resources/Dialogues/Standing/{캐릭터ID}_{표정}` → 없으면 `{캐릭터ID}` |

정식 스탠딩이 있으면 실루엣 위의 글자는 자동으로 사라진다. Day72 정식 리소스 적용 일차에 그대로 쓰면 된다.

## 2. 대화 데이터 — JSON 파일

대사는 코드가 아니라 `Resources/Dialogues/{대화ID}.json`에 쓴다. Day56 보상표 · Day57 취향표는 짧아서 코드 목록으로 충분했지만, 대사는 길고 Day67~69 메인 스토리에서 크게 늘어난다. 파일로 두면 코드를 건드리지 않고 대사만 고칠 수 있다.

```json
{ "id": "EVT_SERENA_01", "title": "치유 연습", "characterId": "CH_SERENA",
  "background": "SANCTUARY_PRACTICE", "location": "성역 · 조용한 연습 자리",
  "nodes": [
    { "id": "n2", "speaker": "CH_SERENA", "expression": "미소", "text": "오셨군요, 용사님..." },
    { "id": "c1", "speaker": "CH_SERENA", "text": "어떻게 해 볼까요?", "choices": [
        { "text": "기도의 뜻부터 묻는다", "affinity": 3, "preferred": true, "next": "a1" },
        { "text": "손동작을 한 번 더 따라 해 본다", "affinity": 1, "next": "b1" } ] },
    { "id": "a4", "speaker": "CH_SERENA", "text": "...", "next": "m1" },
    { "id": "m8", "speaker": "NARRATION", "text": "...", "next": "END" } ] }
```

| 항목 | 규칙 |
| --- | --- |
| `speaker` | 캐릭터 ID(이름은 CharacterData에서 조회) · `HERO`(이름표 "나") · `NARRATION`(이름표 없음 · 기울임) |
| `expression` | 기획서 12.3 표정 이름 (미소 · 진지 · 당황 · 슬픔 · 부끄러움 · 놀람 · 상처 · 각오 · 경계 · 흥미 등) |
| `next` | 비우면 **바로 아래 노드**, 노드 ID면 그곳으로, `END`면 종료 |
| `choices` | 선택지. `affinity`는 호감도 변화, `preferred`는 캐릭터 선호 성향(기획서 9.11) |

주인공 이름표는 임시로 **"나"**다. 기획서상 이름은 플레이어가 정하므로(3.2), 프롤로그 일차에 이름 입력을 만들면 바꾼다.

## 3. Runtime

화면(`DialogueOverlayView`)과 진행 로직을 분리했다. 진행 로직은 Unity 없이 테스트할 수 있는 순수 C#이다.

| 클래스 | 역할 |
| --- | --- |
| `DialogueScript` | JSON 데이터 구조 (대화 · 노드 · 선택지) |
| `DialogueLibrary` | `Resources`에서 불러와 캐시. **구조 검사**(`Validate`): 중복 노드 ID · 없는 `next` · 대사도 선택지도 없는 노드 · 허용되지 않은 화자 |
| `DialogueRunner` | `Current` · `Advance()` · `Choose(i)` · `SkipToChoiceOrEnd()` · `Log` |
| `DialogueService` | 저장 연결: 개인 이벤트 상태 · 완료 보상 · 일상 대화 1회 제한 |

### 진행 규칙

- 선택지 노드에서는 `Advance()`가 거부된다. **반드시 골라야** 넘어간다
- 선택지로 오른 호감도는 바로 반영하지 않고 **쌓아 두었다가 대화가 끝날 때 한 번에** 반영한다
- 그래서 대화 도중에 화면이 사라지면 아무것도 바뀌지 않는다 — 중간에 끄고 다시 봐서 선택지 호감도를 두 번 받는 일을 막는다
- `SkipToChoiceOrEnd()`에는 노드 수 × 4 반복 제한을 걸어, 대사 파일에 순환 분기가 있어도 멈추지 않는 일이 없게 했다

## 5. 일상 대화

기획서 9.3의 "대화 — 로비나 밤 시간대에 캐릭터와 대화, 안정적인 기본 상승"을 구현했다.

- 캐릭터 창 하단에 **[대화하기]** 버튼 추가. 현재 시간대의 대화(`TALK_SERENA_MORNING` 등)가 열린다
- 끝까지 보면 **호감도 +2**
- 캐릭터마다 **시간대당 1회**. 아침 · 낮 · 저녁 · 밤마다 한 번씩, 하루 최대 4회

`CharacterSaveData`에 `lastTalkSlot`(일차 × 4 + 시간대) 하나만 추가했다. Day57 선물처럼 **대화할 때 비교**하는 방식이라 시간 진행 코드는 건드리지 않았다. 필드가 없던 기존 세이브는 0으로 시작하는데, 1일차 아침이 이미 4이므로 **처음부터 대화할 수 있다.**

4인 × 4시간대 = **16편**, 편당 2~3줄이다. 기획서 4.5의 "Lv.2 선호 아이템 힌트"에 맞춰 Day57 선물 취향 힌트를 넣었다.

| 캐릭터 | 힌트가 들어간 대화 |
| --- | --- |
| 세레나 | 저녁 — 저녁 기도 때 켜는 **성수 향초** |
| 엘렌 | 저녁 — 갑옷의 **기사단 문장** / 낮 — 몰래 사 둔 **과자** |
| 릴리아 | 밤 — **별자리 지도**가 있으면 밤새 볼 텐데 / 저녁 — 성역 **향초** |
| 이브 | 저녁 — 연못에서 주운 **조개껍데기** |
